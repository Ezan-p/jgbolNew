金箍棒 3.87 开场动画补丁 v102 → v103

内容：恢复包内原版开场动画。每次冷启动播放一次，右上角可跳过，
安卓返回键也可跳过；切到后台暂停，回来继续。动画结束或跳过后准备本地服务，
期间显示加载页，就绪后进入游戏。播放异常自动继续启动。
动画沿用原版画面与声音，修正原视频时间轴并转换为兼容编码。
本补丁不改账号、角色、玩法、数据库或内置后端。

手机直接更新（推荐）：
使用同目录发布的“金箍棒3.87-开场动画更新-v103.apk”覆盖安装。
不需要解压补丁或运行电脑脚本。不要卸载旧版，不要清除应用数据。

小体积补丁用法（需要电脑及 Python 3.8+）：
1. 解压本补丁 ZIP。
2. 准备原“金箍棒3.87-离线单机-arm32.apk”（v102，未修改）。
   如果持有 .apk.zip，先解压得到 APK。
3. 在解压目录执行（把路径换成实际原 APK 路径）：
   python3 apply_patch.py "/原包路径/金箍棒3.87-离线单机-arm32.apk"
   Windows 可将 python3 换成 py -3。
4. 脚本验证原包 SHA256，合成已签名的 v103 APK，并验证最终 SHA256。
5. 将生成的“金箍棒3.87-开场动画更新-v103.apk”复制到手机覆盖安装。

补丁 ZIP 不是可直接在手机安装的 APK；合成无须联网、Android SDK 或签名密钥。
补丁仅接受 v102 离线单机原包；其他版本会被拒绝，不会覆盖原 APK。
包名、签名和存档路径沿用旧版，设备支持范围与原 v102 相同。
构建源码入口：build_opening_patch.py。输出哈希见“校验清单.json”。
