# 九重天离线活动实现说明（3.87）

更新：2026-10-26。适用当前原版客户端＋本地离线后端。

九重天已接入原版入口37、请求1309和事件164，覆盖九层行进、单次／十连、随机奖励、天星／残星兑换、天星卡、九重天宫及集市九重天礼包。它使用原版 `towerUI`，与1353通天塔、1329九幽无关。当前实现不是原官方服务端代码；可证明的客户端规则标【A】，缺失服务器数据的补全标【B】。

## 1. 入口与使用

启动或重启 `启动本地离线游戏.command`，登录后在奇闻／活动入口找到“九重天”。【B】本地每周一北京时间00:00开始新一期，连续开放七天，每日5次免费单掷。单次按钮优先免费，免费用尽后100元宝；十连固定1000元宝，即使有免费次数也走付费。

天星、残星和卡片在九重天内使用；随机获得的普通物品进入背包，魂魄进入神仙魂魄列表。每10次掷骰遇见天宫，左侧买普通奖励，右侧买天星卡，下面预览下次商品。退出再进入可以恢复当前批次最近一个天宫；开始下一次掷骰后上一批天宫失效。集市“全部”另有九重天礼包，不能将它视为通关必掉。

运行入口、后端路由和客户端补丁均已纳入现有启动链，不需要重打APK。配置见 [nine_sky_rules.json](../server_config/nine_sky_rules.json)。关闭 `enabled` 后入口和集市礼包下架，已有礼包仍可打开。

## 3. 缺失规则的补全【B】

以下全部是可修改的本地设计，不宣称等于原服概率或运营数值。

- 周期：北京时间周一00:00起七天；入口默认1级可参加。每期清空距离、天星、残星、卡片、商店购买数和天宫记录；已入背包的物品与魂魄保留。
- 每日免费5次，不补发离线日额度。随机所得免费骰子单独记账，跨日保留，优先消耗当天额度。跨期清空活动内免费骰子。
- 地图：在六种原版路块中等概率选择当前可用者；接近传送阵时排除越过本层终点和会造成下一步无路可走的组合，保证完整执行原版衔接路径并准确晋层。九重天仍可继续获取天星；局部99999步归零，不产生第十层、不清空累计距离。
- 双倍事件每次10%，额外增加5天星；随机宝物事件每次20%。宝物内部权重：40%蟠桃×10、30%银两×10000、20%面额50天星卡×1、10%免费骰子×1。两种事件独立，均由服务端随机决定。
- 每累计10次掷骰遇见一个天宫，当前批次内的所有天宫都可按各自编号购买；下一次掷骰使上一批天宫失效。每个天宫独立限购，重登不刷新。
- 天星卡超额部分按1:1转为残星，绝不返还额外天星。数量、库存、面额、商品价格均服务端验证。
- 榜首使用同一期实际本地账号，距离降序、到达时间升序、角色ID升序。没有参与者时姓名为空；不伪造线上玩家或额外排名奖励。
- 集市九重天礼包每个300元宝，开启得原文明确的王母魂魄×5【A】及补全的蟠桃×100【B】；可在活动结束后开包。原版魂魄合成沿用既有神仙模块。

## 4. 状态、同步与防重复

状态保存在账号存档的 `activity.nine_sky`。后端沿用现有活动事务：先在独立角色副本上扣款、开奖和编码，再保存；失败不会留下扣款或半份奖励。重复序列请求复用原回包，不重新掷骰或发奖；篡改同序列、非法商品、负数数量、过量卡片、过期天宫均拒绝。禁止时钟回退刷新每日额度。

客户端保留原版素材、六路块、行走／传送动画、说明指引、卡片选择器、两种商店及天宫窗口。适配只补同步：原版随机骰子／卡片回调没有完整刷新角色状态，因此在整个批次走完后应用服务器快照；天宫购买发生在动画暂停期间时，先更新余额差值，最终快照也同步更新，避免旧动画结果覆盖新购买。

**跨层同步修复**：原版 `addSwallow` 会在每次换层时调用 `cancelSwallow`。补丁同时核对累计距离已达到本批次最终值，才认定十连完成；不能只依据解除点击屏蔽回调。

礼包1051校验选中的具体背包堆叠、锁定／占用、数量和使用目标；固定扣除该堆叠，不从其他同类物品扣款。集市沿用1057与现有库存持久化流程。

主要文件：[后端](../network_redirect/activity_nine_sky.py)、[客户端适配](../network_redirect/nine_sky_client.lua)、[配置](../server_config/nine_sky_rules.json)。
