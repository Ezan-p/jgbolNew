# 新档开场动画 v105

2026-10-29：动画位置改为角色选择页点击“进入游戏”之后。只有引导进度为0的新角色进入原版 `playMoive` 阶段时播放，应用启动、账号登录和已有进度角色均不播放。动画结束或点击跳过后，调用原版 `moiveFinished`，继续 `beforeNaming` 剧情、命名、头像、选将和后续教学。

使用包内原版剧情和声音，沿用已修复时间轴的兼容视频，时长约48.13秒。视频不压缩存入APK，避免安卓资源文件描述符读取失败。支持跳过按钮、安卓返回键跳过、切后台暂停与返回续播；解码错误或连续15秒无进展时结束播放器并继续引导，避免黑屏卡住。

## 使用

将 [v105 APK](../build/金箍棒3.87-离线单机-arm32-v105.apk) 复制到手机，覆盖安装同签名离线版即可。不要卸载或清除数据。保留现有账号、角色和引导进度；包内不含玩家数据库。设备架构要求沿用ARM32离线版。

完成首次命名后，角色已有引导进度，再次登录不播放。如果在动画中杀进程或尚未完成首次命名，下次进入仍属于新档阶段，会从头播放。动画本身不提交教学阶段或发放奖励。

## 原因与实现

原版 `guideUI.startPlayMoive` 在360渠道分支中直接跳到 `beforeNaming`。新客户端适配只恢复进度0角色的原生视频入口，不修改全局渠道标识。原版结束回调继续负责场景转换和新手状态机。

v103曾把视频放在应用冷启动阶段，v104已移除该启动视频。v105保持启动页直接初始化离线服务，只在新角色引导中调用播放器。同进程切换到另一个新角色仍可播放，不使用“进程内只播放一次”的全局标记。

源码：`network_redirect/opening_client.lua`、`offline_android/patch_opening.py`、`NewRoleOpening.java`、`OpeningVideo.java`。构建入口为 `build_offline.py --version-code 105 --output build/金箍棒3.87-离线单机-arm32-v105.apk`。
