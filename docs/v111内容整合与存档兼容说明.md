## 安装与存档

沿用包名 `com.sygame.jingubang.p360`、原项目签名和 `files/save` 存档目录，可覆盖安装同签名 v110。更新前备份完整同代 `save` 目录，直接覆盖安装，不卸载旧版或清除应用数据。APK 不包含玩家数据库，原正式 v110 安装包保留。

本版实际更换 Android 版本清单、程序载荷及其校验信息、ARM32 原生适配库。原游戏引擎、客户端资源和 Python 运行时保持 v110 原字节；Java 桥重新编译后与 v110 字节一致。签名与 APK 对齐检查通过。

## 升级后的规则变化

- 九幽商店升级货架版本后刷新旧货架和限购；既有库存、魂晶保留。
- 已开始的宝图保留原奖盘；新奖盘与新批量采用 v4。
- 猎魂每周一北京时间零点清空待翻牌和本周挑战进度；保留魂力余额、背包、已开阵位与符咒养成。未翻牌不自动补发，应在换周前领取。
- 太虚已开赛名单继续沿用，新赛程采用新NPC分配。
- 时钟不自动清除旧封锁、不抹平历史日期偏差；完整性保护保留。30天是纯离线补时的接受边界，无法证明设备系统时间真实。
