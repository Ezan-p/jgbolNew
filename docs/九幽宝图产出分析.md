# 九幽宝图产出分析

更新日期：2026-11-13。奖池版本：`2026-11-13-user-pool-v10`。

1—10阶宝图分别模拟免费首抽与每张五抽，每种模式独立运行5组，每组消耗100张新图。合计实际随机抽取10,000张宝图、30,000个中奖格，所有格子均不主动移除，同张中奖格不再参与后续抽取。

每组数量为实际随机抽取后汇总的整数；五组平均为这5组数量之和除以5，表示每100张的样本平均产出。魂晶直接计入九幽货币余额，其余奖励进入背包。三类丹药每次命中1颗，宝图阶数决定丹药档位。
