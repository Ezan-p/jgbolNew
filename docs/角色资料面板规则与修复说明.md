# 角色资料面板规则与修复说明

适用客户端：金箍棒3.87。原验证日期：2026-10-25；接入状态复核：2026-10-26。

本文的【A】表示能从原版安装包中的协议、Lua字节码、CSV或文案直接复核的内容；【B】表示原服务端不可得时，本地实现采用的推测、模拟或兼容策略。【A】不代表已验证原服后台逻辑。

## 已实现范围

角色资料查询、改名、称号列表与佩戴／卸下、首次免费头像选择、付费头像切换、六种天赋切换均已接入原版客户端协议。修改保存到账号的SQLite角色存档，重登可恢复；属性更新先于界面成功回调。称号接入既有战力计算；天赋在带有 `genius_prob` 的旅途关卡中参与实际战斗结算。

实现：[role_profile.py](../network_redirect/role_profile.py)；接入：[backend.py](../network_redirect/backend.py)；配置：[profile_rules.json](../server_config/profile_rules.json)。原版界面保持原来的交互，不替换为新面板。

## 改名

- 【A】原版文案明确为“名称长度为2到7个中文字符”；更名文书编号1005，物品描述说明用于改名，原购买表提供该商品。更名成功后客户端刷新1005物品格与主界面姓名。
- 【A】返回码：1成功、2重名、3非法字符、4过短、5过长、6重复请求、7无道具、8元宝不足。网络姓名字段最多31个UTF-8字节并以零结束。
- 【B】服务端按2–7个CJK统一汉字／扩展A字符校验，拒绝空格、控制符、拉丁字母、标点和表情。这是对文案的保守落实，原服完整字符白名单不可得。
- 【B】每次成功消耗1张未锁定更名文书；不自动用元宝代扣、不免费发文书。文书可通过已实现的原版集市购买。配置保留道具数与禁用词列表；原服敏感词库不可得，默认禁用词列表为空。
- 【B】与当前名字相同返回6；同一角色数据库内其他账号重名返回2。检查名字前取得SQLite写锁，避免两个请求同时通过重名检查。不同隔离数据库之间不声称提供跨服全局唯一性。
- 【B】校验失败不扣道具、不修改姓名；成功后先发道具增量，再发事件12。回放同一请求不会再次扣文书。

证据：`ui_commonLayerUI.txt` 原行271–360；[原版文案](../analysis/evidence/profile/strings.json)；`item_name.csv`、`item_buy_config.csv`。

## 头像

- 【A】原版允许101、102、103、104、201、202、203、204八种头像。不是任意神仙编号。
- 【A】`flag=0`为免费分支，原版提示“首次更换头像免费”；`flag=1`为付费分支，客户端校验200元宝。付费选择限制在同一性别分组：101–104或201–204。
- 【A】旧的无效头像会让主界面进入首次选头像流程；原客户端暂用101展示，选定后清除待选择状态。
- 【B】2026-10-29修复：初始头像选择与免费更换分开，创建角色时选头像不消耗免费更换机会。旧 `profile_head_changed` 同时用于初始选择，无法证明真正使用过免费更换；缺少新字段的存档一次性获得免费机会，以 `profile_head_free_used` 单独持久化，之后重登、重启都不恢复。
- 【B】免费更换可选择任一性别，余额为0也能使用；之后仍为200元宝且只能同组切换。服务端依据存档决定是否免费，旧客户端发送 `flag=1` 也不会误扣首次费用；机会用尽后伪造 `flag=0` 会被拒绝。选择已佩戴头像、非法编号或标志均失败，不扣费也不消耗免费机会。
- 【B】登录配置及角色操作回包同步 `local_profile.head_free_available`；`profile_client.lua` 据此调用原版免费／付费选择框，首次不会被200元宝余额检查拦截。更换成功前同步剩余机会，失败不产生无关玩法存档变更。
- 【B】付费扣200元宝与头像变更一并保存。余额不足返回8。非法请求用6表示失败，避免原客户端把头像事件的返回码3也按成功处理。

证据：`ui_runeUI.txt` 原行96–106、132–138、267–312、352–417，`ui_mainUI.txt` 原行687–690。

- 【B】关卡 `genius_prob`按0–100百分比解释。没有该字段的战斗不自动触发；零概率不触发。动画标志与服务端结算使用同一次判定，单体 `use_order`为目标阵位、群体为0。切换后影响下一场战斗，不把本场临时增益写成永久属性。

## 持久化、重放与验证

【B】角色请求使用独立的256条响应缓存：同序号同报文原样回放；旧序号或同序号不同内容拒绝执行。重新认证清空会话序号缓存，业务状态仍保存在SQLite中。跨进程重启不承诺保存网络响应缓存；重新登录后按实际存档校验道具、名字、头像与称号。

以下为2026-10-25该次实现的历史验证；本轮文档复核未重跑这些测试或操作实际存档。验证结果：

- 新增11项测试通过，覆盖全部六种天赋等级边界、全部57个称号、扣费／道具扣除、失败原子性、重名、免费头像防重用、请求重放、过期、存档重载、天赋实际增益与零概率。
- 全量581项测试执行完毕：561项直接通过；20项本机网络测试因沙盒禁止监听端口报错，允许本机回环访问后20项全部通过。
