# 仙盟模块离线补全说明

日期：2026-10-25。适用版本：金箍棒 OL 3.87、本仓库 Python/SQLite 后端。配置修订：`guild-offline-2026-10-25`。

本次依据《仙盟模块剩余功能分析》继续开发，以单账号离线可玩为目标。保留原客户端与现有存档；多人由本地 NPC、日常积分杯和护送事件代替。下文所有新增数值均为推测配置，不代表官方服务器规则。

## 1. 如何体验

重启本地离线后端、重新进入游戏，使配置段 8 和后端代码一起生效。无需删除存档。

1. 创建仙盟后，在申请列表批准“离线求道者”；也可加入“本地仙盟”，直接与离线道友组队。
2. 原客户端捐赠入口要求角色达到 36 级或 VIP 大于 0。满足条件后，新盟先捐献 50 元宝获取 50 威望，再种植神树。固定任务消耗银两，随机任务轮换装备、竞技令牌、传功道具和银两。
3. 创建秘境队伍后，申请列表会出现本盟 NPC。勾选并同意即可组队，最多三人；加入 NPC 队伍由 NPC 自动审核。
4. 寻宝生成并保存 25 格奖励棋盘。单次探索与扫荡使用同一棋盘；扫荡剩余次数一次扣 10 元宝，无次数或元宝不足时不扣费。
5. 游历后可尝试捕捉。成功率默认 70%，失败允许重试，第三次失败逃走；关闭捕捉窗口会放弃当前目标。优先消耗背包中的下品镇魂符 1338 并增加 15 个百分点成功率，否则扣 20 元宝。
6. 在仙盟聊天输入下列命令养成兽栏灵兽。返回信息也保存在聊天记录中。

| 命令 | 功能 |
|---|---|
| `/灵兽` 或 `/灵兽 2` | 分页查看实体编号、类型、品质、等级、星级、战力；每页三只 |
| `/喂养 1` | 给 1 号灵兽增加 25 经验，消耗 1000 银两；100 经验升一级 |
| `/合成 1 2` | 保留 1 号，消耗同类型且品质不低于它的 2 号，品质增加一级 |
| `/升星 1` | 消耗另一只同类型灵兽及“当前星级 × 20”声望，增加一星 |

编号为兽栏实体 ID，**不是灵兽类型 ID**。等级上限 50，品质上限 5，星级上限 5，兽栏上限 240。没有复用洞府的个人宠物记录，也没有给原 APK 虚构不存在的养成按钮。

7. 本服和“跨服”分别运行独立的离线积分杯。报名、押注后战斗；不同职位功勋不同，失败扣生命。主动领奖即结算本轮，领奖后不能继续战斗或补下注，次日重开。
8. 取经可向 NPC 请求护送。获得护送资格后选该成员出发，或在途中请求保护；保护降低被劫概率。被劫记录可加入黑名单，追击对应离线目标有额外贡献。

## 3. 关键离线数值

配置路径：`server_config/guild_rules.json`。

| 配置 | 默认规则 |
|---|---|
| `tree_require_pop` | 50 威望 |
| `apply_daily` / `join_daily` | 每日 10 次申请 / 3 次加入 |
| `rank_limits` | 副盟主 1、护法 2、长老 4、精英 8 |
| `search_sweep_gold` | 扫完当日剩余次数共 10 元宝 |
| `match_life` / `match_loss_life` | 初始生命 100，失败扣 25 |
| `match_target_loss` | 胜利扣目标 20 生命，归零后不可再挑战 |
| `match_merit` | 盟主 5；副盟主/护法 4；长老 3；精英 2；盟员/见习 1 |
| `match_max_streak` | 连胜计数上限 5 |
| `train_hp` / `train_seconds` / `train_support_limit` | 试炼生命 10000 / 一小时 / 三次援助 |
| `catch_success_percent` | 基础捕捉成功率 70% |
| `catch_item` / `catch_item_bonus` | 下品镇魂符 1338，增加 15 个百分点 |
| `hunt_weekend_open` | 默认 true；设 false 后周末不能做任务 |
| `hunt_paid_limit` | 每日三次付费任务 |

灵兽战力为 `品质 × 等级 × 星级 × 20`。兽栏总战力每 100 提供 1% 属性加成，最高 100%，作用于秘境、灵兽试炼和灵兽任务战斗。NPC 队友协助额外计算，宴席加成沿用既有规则。

取经途中满半小时后的首次请求判定一次劫掠：未护送概率 50%，有护送概率 10%；被劫后完成时贡献和仙盟资金减少 20%，不减少经书碎片。黑名单目标拦截胜利贡献由 10 提升至 15。品质刷新至少升一级，20% 概率升两级，最高五级。

## 4. 存档与边界

- NPC 盟在首次迁移时补入，不覆盖已存在仙盟；使用与玩家自建盟不同的 ID 段。
- 旧兽栏类型列表迁移为实体列表。旧占位 ID 1–6 和不存在的 106 映射到有效类型，后续生成只使用原表存在的类型。
- 新增随机操作使用持久化随机序列。失败请求不保存随机序列、扣费或奖励；重复请求继续使用已有会话缓存。随机性用于离线玩法，不作为对抗作弊的密码学随机数。
- 日界线沿用 UTC+8；周积分按周一换周。次数、材料和领奖状态不因退出再加入刷新。
- 后端先在角色副本上结算、编码，再保存。数据库原子保存不代表跨进程事务幂等；请沿用单一后端进程。
- 未尝试恢复真实跨服、官方赛程时间窗/晋级/败者组、官方概率或官方宠物属性公式。相关入口有明确的离线替代规则；未知无入口协议仍明确拒绝。
- 原《剩余功能分析》保留作为改动前快照；本说明与当前代码是新增规则依据，旧《规则与调试》中的固定数据规则不再全部适用。
