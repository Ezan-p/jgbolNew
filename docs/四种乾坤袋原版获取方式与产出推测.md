# 四种乾坤袋：原版获取方式、可证产出与推测（3.87）

分析日期：2026-10-26。对象为VIP乾坤袋1031、金丝乾坤袋1032、银绸乾坤袋1033、棉布乾坤袋1034。本文依据本仓库原始3.87资源，先写原版证据，再写推测；未取得原服服务端抽奖表或历史结算样本。

**结论：原包能支持“哪些东西注明来自乾坤袋”，但仍不能把这些东西准确分配给四种袋子，也不能还原逐项概率。2026-10-26补充全表功能道具／材料审查：820条物品中排除109条装备成品，逐项核查其余711条；其中6条有开袋来源文案，8条列为通用资源假说，17条列为更弱的进阶资源假说，680条暂不纳入。711是审查范围，不是开袋奖池大小，更不能据此认定“所有功能道具或养成材料都能开出”。详见第8.2—8.5节及逐项附件。**

本文中的“原版有配置”表示客户端包含这条规则或奖励，不保证该活动在每个服务器、每个运营时期均开放。“来源文案”不保证是完整清单。“推测可信度”是证据强弱的定性判断，不是概率。

### 6.2 不能直接加入已确认开袋池的东西

- 七星鞭、九环锡杖、七星伏魔剑、VIP专属来源防具：有固定VIP等级礼包证据，没有对应的乾坤袋来源文案。
- 五星法宝成品、四星法宝成品、6004五星法宝碎片：不能因“法宝也是装备”就自动加入开袋池。尤其四星法宝存在另一些权重线索，但未绑定到四种袋子。
- 八种五星普通被动法术、6005五星被动碎片、大乘经：前两类有渡劫／经书袋／寿星等其他来源；大乘经为如来专属。原文案未将其绑定乾坤袋。
- 银两、蟠桃、高级／超级召唤符：当前离线VIP袋会投放其中若干，但这不能反证原版四袋也按同样比例投放。
- 星宿仙术、精魄、神仙整卡／魂魄：本次未找到把它们直接绑定四种乾坤袋的原版产出表。

这些条目应记为“未证实”，而非“原版概率必定为0”。

### 6.3 概率结论

四袋原版逐项概率、品质概率、保底、额外掉落和单袋产出件数均未知。`item_base.random_weigth` 的7个非零条目没有袋种维度；碎片合成表的权重20属于合成；两者都不能直接转换成开袋概率。

当前离线VIP袋的50%银两、25%蟠桃、15%人参果、9%高级符、1%超级符，是本地 `mode=inferred` 奖池，不属于本部分原版结论，也不作为下文推测的历史证据。

### 8.1 VIP袋存在两种都能解释证据的假说

**假说A：装备抽奖的VIP档。** 它与金丝共享高星候选，给予VIP更好的品质分布或附加资源。支持线索是“罕见宝物袋”文案、中后期固定奖励和VIP开启限制。

**假说B：VIP资源福利袋。** 它主要产出传承、培养、召唤等资源，与金丝的装备定位不同。支持线索是VIP入口和促销定位，但原包没有直接列出这套内容；目前的离线资源池只能作为设计实例，不能提高这条历史假说的可信度。

现有证据无法排除任一假说，也可能实际采用混合机制。将VIP简单排成“棉布＜银绸＜金丝＜VIP”会超出证据。

## 9. 可能的抽奖结构

至少有三种模型都与当前静态资料相容：

1. **共享候选、不同权重。** 四袋使用相近物品集合，高档袋增加高品质权重。
2. **不同品质上限或专用候选。** 棉布／银绸／金丝各自有不同池，部分高星只进入高档袋；VIP另有专池。
3. **分层抽奖或额外奖励。** 先抽资源／装备／法术，再抽品质与具体物品；或基础奖加额外奖。这样即使物品基础表某权重相同，最终概率也未必相同。

原客户端的批量开启和返回奖励列表，不能区分上述模型；返回多条奖励也可能只是多袋结果合并。没有服务端抽奖逻辑前，不应把“每袋独立只抽一项”直接写为原版规则。

**本报告不为这些假说编造百分比。** 当前没有足够约束让“金丝五星5%”比“金丝五星1%”更有证据支持；给出精确数字只会把设计选择伪装成解析结果。如果后续需要离线实现，应另立“本地奖池设计”，逐项记录哪些是原版候选、哪些是新增假设。
