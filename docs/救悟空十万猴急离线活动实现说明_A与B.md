## 1. 已接通的流程

1. 奇闻中的“救悟空”进入“十万猴急”；沿用公共入口原本没有额外固定等级的行为。
2. 首次进入领取本期初始工具和当日登录工具；完成现有日常任务领取活跃度工具礼包。
3. 使用定风珠、爆火珠、链雷珠破石，使用火眼金睛侦察；救猴加积分并发放固定奖励，破石增加碎石，发现起爆符自动连锁。
4. 累计积分领取阶段礼包；碎石购买工具和材料；仙人助力按原版四档配置兑换。
5. 同期充值可在解锁前累计，积分和充值都达标后自动邮件发放道尊金卡。道尊金卡可从背包使用，且不增加本活动充值累计、工具充值礼包或特权返卡。
6. 进度、地图、消耗、兑换限次和领奖状态保存到角色存档；重启继续，重复提交不重复扣发。

## 3. 缺失部分的推测规则 B

主配置：[save_monkey_rules.json](../server_config/save_monkey_rules.json)，显式标注 `mode: inferred`。原版四档仙人助力配置与大小猴固定奖不放入可随意改动的 B 奖池。

### 3.1 开放、地图、破石与刷新

| 缺失内容 | 当前 B 补全 |
|---|---|
| 原服活动日期 | 默认常驻，每周一北京时间00:00换期；配置周期7天。关闭开关后入口和服务端操作均关闭。 |

| 单次工具成本／伤害 | 每次消耗1枚所选宝珠；每个命中的可破坏格扣1点耐久，同一操作中被多个爆炸覆盖也只扣一次。只有完全破坏才产出碎石和内容物。 |

| 藏物显示 | 未侦察时，仅显示与空格八邻接的内容物；火眼金睛有效区间为使用时当前顶行深度 `d` 至 `d+29`，只发送范围内的隐藏道具。有效期间拒绝重复消耗。 |
| 重启 | 保存实际生成地图，重新进入不会重抽；客户端也不会收到远处尚未侦察的内容物。 |

非花岗岩的藏物权重：定风珠10%、爆火珠5%、链雷珠5%、起爆符5%、大猴8%、小猴17%、空50%。各格独立随机；花岗岩不藏奖励。猴子救出后直接结算，不把猴子图标作为可重复使用的背包奖励。没有添加额外随机救猴奖励。
