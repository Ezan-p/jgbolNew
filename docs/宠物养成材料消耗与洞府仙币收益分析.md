# 宠物养成材料消耗与洞府仙币收益分析

核算日期：2026-11-09。适用范围：当前工作区源码与实际加载配置。本文整理宠物升星、培养、幻化的材料消耗、洞府修炼果需求，以及洞府日常和福利的仙币收入；不修改游戏规则、存档或APK。第9节保留此前拟议价格的历史测算；2026-11-09实际商店调整见9.3节及[洞府商店说明](洞府离线活动实现说明.md#商店与持久化)。

【A】表示原客户端或原版／热更新配置可确认的内容；【B】表示当前离线服务端补全的规则。本文给出的总量按当前实现计算，不代表取得了原服私有服务端规则。已有APK是否适用，取决于是否包含对应更新。

## 1. 核心结论

- 一只品质4宠物从0星养到9星并完成全部培养，固定消耗驯养丹23,120颗、妖王丹28颗、仙气灵70个、神元精90个，以及45只符合要求的升星材料宠物。
- 品质3上限为6星，完成全部培养需驯养丹7,120颗、妖王丹28颗、仙气灵70个，以及30只符合要求的升星材料宠物。
- 规模3、药园和佛堂50级、8块30级药田，在按时收种、施肥及除虫的条件下，24小时西瓜路线含祈愿约35,048仙币／日；12小时菩提果两轮路线约207,312仙币／日，另需每天1,760元宝购买种子。
- 洞府福利中的仙币合计50,600，为一次性奖励，不能计入每天重复获得的收入。
- 四项洞府修炼从0到40级，若经验全部由修炼果提供，共需333,795个；按拟议的30个／10,000仙币档购买，总成本111,270,000仙币，不含修炼房建设等开支。四项经验需求不同，不能把攻击修炼成本直接乘4。

## 3. 宠物满星、满培养的固定消耗

### 3.1 总量

计算起点为一只已具备相应品质、尚未升星的宠物；不计获得该宠物、融合提高品质、吞噬升级及幻化的额外成本。

| 材料 | 品质3：0→6星并满培养 | 品质4：0→9星并满培养 |
|---|---:|---:|
| 驯养丹 | 7,120颗 | 23,120颗 |
| 妖王丹 | 28颗 | 28颗 |
| 仙气灵 | 70个 | 70个 |
| 神元精 | 0 | 90个 |
| 升星材料宠物 | 30只 | 45只 |

每次升星直接消耗5只材料宠物，有指定类型、品质要求，且必须为0星；并非任意宠物均可充当材料。上述数量不含为取得指定品质材料宠物而额外消耗的融合材料。

### 3.2 各星级明细

“本星满培养”指到达该星级后，再完成四个方向各4次培养。每次升星按升星前的星级读取材料表。

| 升星阶段 | 本次升星道具 | 本次材料宠物数 | 到达该星后每次培养所需驯养丹 | 本星满培养所需驯养丹 |
|---|---|---:|---:|---:|
| 0→1星 | 妖王丹×5 | 5 | 15 | 240 |
| 1→2星 | 妖王丹×8 | 5 | 30 | 480 |
| 2→3星 | 妖王丹×15 | 5 | 50 | 800 |
| 3→4星 | 仙气灵×10 | 5 | 80 | 1,280 |
| 4→5星 | 仙气灵×20 | 5 | 120 | 1,920 |
| 5→6星 | 仙气灵×40 | 5 | 150 | 2,400 |
| 6→7星 | 神元精×15 | 5 | 200 | 3,200 |
| 7→8星 | 神元精×25 | 5 | 350 | 5,600 |
| 8→9星 | 神元精×50 | 5 | 450 | 7,200 |
| 合计 | 妖王丹28＋仙气灵70＋神元精90 | 45 | — | 23,120 |

计算式：

```text
9星满培养驯养丹 = 16 × (15＋30＋50＋80＋120＋150＋200＋350＋450)
                 = 23,120
6星满培养驯养丹 = 16 × (15＋30＋50＋80＋120＋150)
                 = 7,120
```

只升到9星而不培养9星阶段，驯养丹为15,920颗；补满最后一星再花7,200颗。只升到6星而不培养6星阶段，驯养丹为4,720颗；补满最后一星再花2,400颗。

虽然原表含9星行的升星材料字段，当前最高9星，不能再升10星，故不重复计入该行的升星材料。0星行的培养消耗字段同样不计入，因为当前服务端不允许0星培养。

依据：[宠物培养表](../analysis/configs/animal_train_config.csv)【A】及[当前宠物结算](../network_redirect/pets.py)。宠物等级最高200级，升级通过吞噬获得经验；消耗取决于材料宠物的类型、品质和已有经验，不包含在上述满星、满培养总量中。

## 4. 洞府每日仙币收入的核算口径

日常可重复收入主要是药园收获和每日祈愿。下表不包含天仙令兑换、礼包、兑换码及一次性福利，也不把银币、元宝混算成仙币。

统一假设：

1. 药园和佛堂等级相同；所有药田已升级到该药园等级允许的最高等级。
2. 西瓜、人参果选24小时种子，每天收一轮；仙桃、菩提果选12小时种子，每天收两轮。全部药田种同一种作物。
3. 按时收获、续种并处理虫害，每天用好10位NPC邻居各一次的邀请施肥机会。
4. 表内为稳定种植后的日均收入，不代表刚建药园或刚播种当天立即到账。祈愿按七次循环平均；少量小数四舍五入。
5. 数值为仙币到账量；种子所需银币、元宝及药田升级、助手费用另计。成熟后的等待时间会降低长期日均收益。

当前实际加载热更新后的药园、佛堂及药田配置，最高分别为50级、50级、30级。药园15级起有8块田；之后提高药园等级主要是解锁更高药田等级。旧版20级建筑、12级药田的上限不能用于当前满配核算。

## 6. 收获计算、施肥与虫害

当前服务端按以下顺序计算单块药田、单轮仙币：

```text
加成后产出 = floor(基础产出 × (100＋药田加成＋规模加成＋施肥加成) / 100)
最终产出 = max(1, floor(加成后产出 × max(0, 100－10×漏处理虫害次数) / 100))
```

| 加成来源 | 当前数值 |
|---|---|
| 洞府规模 | 规模1／2／3分别为0%／5%／20% |
| 药田等级 | 1级5%、7级35%、13级65%、19级130%、24级220%、30级350% |
| 邻居施肥 | 每次增加5个百分点 |
| 每轮施肥次数上限 | 西瓜5次、人参果6次、仙桃8次、菩提果10次 |
| 漏处理虫害 | 每次使该轮加成后收获减少10% |

每天10位邻居各可应邀一次；一次邀请为所有尚未成熟、未达施肥上限的药田各施肥一次。每天两轮作物共享当天这10次邀请，不能把两轮都按满施肥计算。本表仙桃按8＋2次、菩提果按10＋0次分配，计算每轮取整后的总量。

助手可以在覆盖虫害事件窗口时免除该次损失，但需支付元宝；也可以按时手动除虫。助手费用不计入种子成本表。

满配西瓜示例：

```text
每块田 = floor(870 × (100＋350＋20＋25) / 100) = 4,306仙币
每日药园 = 4,306 × 8 = 34,448仙币
含50级佛堂祈愿 = 34,448＋600 = 35,048仙币／日
```

满配菩提果示例：

```text
第一轮每田（10次施肥）= floor(2,610 × (100＋350＋20＋50) / 100) = 13,572
第二轮每田（0次施肥） = floor(2,610 × (100＋350＋20) / 100) = 12,267
每日药园 = (13,572＋12,267) × 8 = 206,712仙币
含50级佛堂祈愿 = 206,712＋600 = 207,312仙币／日
```

原表提供种子、药田和规模参数【A】；本地NPC协作、每次施肥增益及虫害扣减采用当前离线实现【B】。依据：[药田配置](../analysis/configs/immortal_hotupdate/hole/garden_grid_config.csv)、[规模配置](../analysis/configs/hole/hole_owner_config.csv)、[收获逻辑](../network_redirect/activity_home.py)、[邻居协作逻辑](../network_redirect/activity_home_friends.py)。

## 9. 洞府修炼果消耗与拟议价格分析

### 9.1 用途、经验换算与上限

修炼果（1364）用于洞府修炼房的攻击、防御、法伤、法抗修炼，与宠物培养所用的驯养丹不同。原配置中每个修炼果提供200修炼经验【A】，没有每日使用次数上限，但受修炼房允许的修炼等级限制；当前修炼房最高20级，对应四项修炼最高40级。

| 修炼方式 | 每次消耗 | 每次经验 | 当前每日次数限制 |
|---|---:|---:|---|
| 银币修炼 | 2,000,000银币 | 200 | 四项共用10次 |
| 元宝修炼 | 50元宝 | 200 | 无每日次数上限，受修炼等级容量限制 |
| 修炼果修炼 | 1个修炼果 | 200 | 无每日次数上限，受修炼等级容量限制 |

银币档每天最多贡献2,000经验，相当于10个修炼果，需消耗2,000万银币。其他方式取得的经验、活动奖励的修炼果及已有修炼进度，都会减少实际需要从商店购买的数量。

依据：[修炼经验与消耗配置](../analysis/configs/hole/add_experience_config.csv)、[修炼房上限](../analysis/configs/hole/train_building_config.csv)、[当前修炼结算](../network_redirect/activity_home.py)。

### 9.3 当前价格与历史拟议价格的差异

### 9.5 对培养周期的影响

按拟议30果包所需111,270,000仙币，假设始终保持第5节对应收入、所有仙币都用于购买修炼果、不受货源限制、不计其他奖励与修炼方式，则攒币时间为：
