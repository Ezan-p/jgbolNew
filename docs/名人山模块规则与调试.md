# 名人山模块规则与调试

版本：原版客户端 3.87；修复日期：2026-10-25。

本文的 **【A】** 表示能从本项目保留的原版客户端字节码、协议定义或资源表确认的行为；**【B】** 表示缺失服务端后的本地推测、模拟及兼容修复。没有原服服务端源码、配置或历史数据库，因此不能把离线赛事、数值和冠军名单称为官方还原。

## 修复范围

名人山对应 `ui/monumentUI.lua`，不是单独的封神榜页面。已接入冠军请求、五座展示及五个跳转入口，修复首次进入异常、公开赛程的入盟拦截、财富榜与冠军数据不一致、跨服个人榜缺失服务端、战报缓存及周刊旧网址问题。

- 冠军展示：跨服仙盟战、本服仙盟战、财富、封神榜、跨服个人榜。
- 五个入口：复用原版 `crossRealm`、`guildFightUI`、`guildPartyUI`、`rankUI`、`crossRankUI`，保留原版页面和返回流程。
- 既有封神榜、仙盟战及宴席的参与、战斗和结算继续使用已有活动／仙盟实现；未入盟也可查看公开赛程、冠军和财富榜，报名、押注、出战等仍检查成员身份。
- 新增跨服个人榜离线实现：赛程配置、对手、刷新、阵容查看、挑战、积分／排名、普通／王者／付费阶段、连胜奖励、排名奖励、战报与重播。
- 周刊：原按钮打开本地提供的中文周刊页，明确标明离线模拟内容，不伪造原服历史新闻。

### 冠军、排行榜与公开查询

1. 本地存档隔离：每个本地账号维护独立模拟世界，不聚合其他账号的私有存档；“跨服”代表原版玩法入口和离线对手，没有真实跨服服务器。
2. 封神榜：当前账号达到第1名时展示账号主阵位模型与姓名，否则展示本地第1名守榜者，与现有封神榜规则衔接。
3. 仙盟：使用现有 `guild_match.tournament` 的当前排名第一；玩家所在仙盟获胜且玩家为盟主时展示玩家模型，其他情况采用配置中的离线模型。未入盟观察现有公共仙盟，不自动创建或加入仙盟。冠军详情补齐届次、等级、威望、盟主、成员列表等原版字段；本服参赛盟按连续数组发送，盟主取存档中的实际盟主。当前模拟冠军卡片不代表原服往届记录。
4. 财富：合并当前模拟世界各仙盟当日宴席统计，按财富降序、贡献降序、ID升序排序；冠军和财富榜使用同一来源。没有记录显示“虚位以待”，不凭空给账号发财富或冠军。
5. 跨服个人榜：玩家与5名明确标注“离线”的对手按积分降序、玩家ID升序排名。对手ID为92001–92005，初始积分依次500／400／300／200／100。模型5004，等级10。玩家模型使用当前主阵位。
6. 冠军为查询时的本地领先者，不宣称是原服某届历史冠军；仙盟赛程、押注和奖励仍见[仙盟模块规则与调试](仙盟模块规则与调试.md)。

### 模拟赛事

- UTC+8每天一轮；默认00:00–20:00普通阶段、20:00–23:00王者阶段、23:00至当日结束付费阶段。时间由 `phase_seconds` 配置，原客户端自行计算显示阶段。
- 6级可参与；低等级可看冠军与跨服个人榜，但不可刷新、挑战和领取赛事奖励。
- 普通阶段显示3名对手，刷新轮换；后续阶段显示全部5名离线对手。不是原服匹配算法。
- 普通付费挑战20元宝；付费刷新10元宝；免费次数、刷新间隔、王者和全付费阶段价格沿用上述原版常量。阶段切换重置挑战计数；免费刷新额度按天重置。
- 服务端验证对手ID、当前排名和付费标记，以服务端阵容计算胜负，原版战斗动画播放结算结果。战斗采用已有离线战斗引擎及其推测机制，并不宣称恢复官方战斗公式。
- 胜利增加100积分，失败增加10积分；胜利累加连胜，失败清零当前连胜，保留当日最高连胜。积分跨日保留，按积分重新计算名次。
- 连胜3／5／10次的奖励分别为银两3000、蟠桃（1001）10、超级召唤符（1007）1；当日每档最多领取一次。原服连胜奖励配置缺失，因此这些值全部标【B】。
- 当日至少参战一次即可按领取时名次领取一次排名奖励，物品沿用原CSV；**即时领取资格和每日一次属于【B】**，不是原服赛季结算时间的证据。
- 保存最近5场当日战报；跨日清空；按原版数据包预算保留可完整传输的最新记录。支持原版战报查看与重播。
- 所有消耗和奖励在验证、编码成功后保存；不足额、无资格、重复领奖、非法对手不落盘。相同请求重放返回缓存，不重复扣款或发奖；过期序号被拒绝。领奖标记存入SQLite，重启仍有效。

### 周刊原生窗口修复

- 【A】原版 `gotoWeekly→main_server.performWebview→xiyoujilua.gotoCharge` 会启动 `com.sygame.jingubang.ChargeActivity`；该类虽名为Charge，实际也是周刊使用的WebView容器，原版布局为 `charge_layout`。
- 本地登录版 `build_local.py` 之前移除这一Activity声明，实际点击原版周刊入口会退出应用。现保留该原版声明和布局，重新构建并签名本地包，versionCode升为90；启动器可覆盖升级87／88／89并保留账号存档。未恢复渠道支付接口。
- 【B】旧周刊站点内容无法还原，因此 `/dailypaper` 返回本地说明页，明确标注模拟规则。恢复的是原有网页入口、浏览容器和关闭返回能力。


- 覆盖升级后的真实服务验证：原账号进入主场景，名人山 `1128→2998/130` 正常显示，客户端兼容补丁自动加载。周刊原版按钮成功打开WebView，实际 `/dailypaper` 返回HTTP 200；见 [周刊截图](../analysis/evidence/monument/live_weekly.png)、[HTTP记录](../analysis/evidence/monument/live_weekly_http.json)、[安装包哈希及组件](../analysis/evidence/monument/package_browser.json)。
