# 本地账号登录

默认安装包为 `build/jgbol3.87-local.apk`（versionCode 91，修复切换账号重新登录）。包名保留，覆盖安装保留 Android 应用数据。游戏内容仍为 3.87。

双击 `启动游戏.command` 或 `启动本地离线游戏.command`，等待服务自检完成，连接画面后点击“进入游戏”。游戏内弹出本地登录窗口，选择“注册新账号”注册。账号为 3–24 位英文字母、数字或下划线，不区分大小写；密码为 8–128 个字符。注册后直接登录。默认勾选“下次免登录（30 天，仅此设备）”，再次进入游戏时自动恢复上次账号，无需输入密码。取消勾选后仅本次登录有效；免登录到期后重新输入密码即可。自动登录前留有3秒取消时间，点击本地窗口“切换账号 / 取消免登录”可清除凭据并登录其他账号。点击游戏启动画面的“切换账号”会立即撤销免登录凭据及旧会话，必须重新输入账号密码；冷启动时同样生效。“进入游戏”仍支持已勾选的免登录。原客户端普通进入也会调用渠道的 switchAccount 接口，安装包会消费其 `acc_login_change_switch` 一次性标记，区分普通进入与明确换号。

每个账号独立保存角色、背包、货币及各玩法进度。账号与存档位于 `.runtime/offline/game.sqlite3`，不会发送到 360 或其他渠道。密码使用独立随机盐及 PBKDF2-HMAC-SHA256（600,000 次）保存，不存明文。游戏会话在服务重启后失效，最长 12 小时；启用免登录后，设备以独立的 30 天凭据自动换取新会话，服务重启不要求重新输入密码。凭据保存在应用私有 Cookie 中，服务端只保存其 SHA-256 摘要；不保存明文密码。切换账号时撤销免登录凭据，重新登录会撤销旧连接、票据和重连凭据。单机同时运行一个账号。

注册页已移除旧存档继承选项，新注册账号直接创建全新存档。原有账号及旧存档保留，不自动覆盖或删除。密码不提供邮箱找回，请自行妥善保管。

安装包已永久替换 `login/switchAccount` 入口，停用 360 SDK 初始化、支付、论坛和相关 Android 组件。保留原协议要求的渠道编号 107 作为兼容字段，不代表调用渠道认证。Frida 仅继续承担原客户端网络重定向、TLS 兼容和玩法补丁，不再注入共享测试账号。服务关闭时本地窗口无法连接，不会回退到 360。

构建：`python3 build_apk.py`。输入为项目保留的 `build/jgbol3.87-360-list.apk`，无需已缺失的 3.79 解压目录。启动器检测旧版本并自动覆盖安装；发生注入故障仍可用 `自动修复登录.command`。当前安装包使用本项目默认端口 18770。

备份时先停止本地服务，再复制整个 `.runtime/offline/`。账号与存档需一起备份、一起恢复。
