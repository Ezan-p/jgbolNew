## 2. 玩家可用流程与经济

70级进入“活动→九幽”。首次领取40颗1442药灵丹、100,000银币、50元宝；原药灵丹每颗25经验，40颗共1,000经验，可由1级升到4级。用50元宝学习四类初阶配方（攻击／防御／气血／灵力，分别10/10/10/20元宝），购材后即可稳定炼制初阶极品药。可按当前敌人选择用药，不要求每层必须用满六槽。

每次真实胜利推进一层、清除药效并发放：

- 原表经验丹／成长材料道具【A】。
- `max(1, 原表魂晶数量//100)`魂晶【B】：第1层604，第81层1,724，81层合计90,005。
- `100000+20000×通关层数`银币【B】：用于后续购材，首胜有限，不能反复刷同一层。
- 随关卡递增的炼药熟练度【B】：把原表4→36级累计经验按72层线性推进“等级进度”，再按每级实际经验门槛插值；每层只领两点累计曲线之差。课程合计1,753,450熟练度，配合入门药灵丹可在72层前后达到36级。它不是每层固定大量经验，前期不会直接跳满级。
- 自动领悟课程开放等级与本人当前等级均满足的配方【B】。已经学过的不重复授予或退费；提前花元宝学习仍可用。

每天5场有效冥仙战斗，失败／平局也扣次数，保留层数与用药；拒绝请求不扣。最多30完整回合，结束时比较当前总气血（包含未登场存活替补），相等为平局。81层获胜后可继续挂机、事件、炼药、宝图、商店和榜奖，禁止重复最终首胜。

挂机仍每300秒一次、离线最多48小时，四组原表掉落全部保留。魂晶为 `min(所在狱上限, max(1,战力//1000))`，双倍再×2。挂机与宝图提供额外药灵丹、养成道具；临时背包一格存一种类型／等级，满格仍能叠加已有种类，仅新增种类无格时舍弃。上限30格、20元宝扩1格至60格不变。

日商店保留每日6种、原有价格与限购；最贵6种全买完为17,700魂晶。第九狱普通挂机一天3,168、全天双倍6,336；81层首胜总量降到90,005。通关阶段仍可攒魂晶，通关后有持续消费选择，原先单层60,400—172,400与低价商店的量级错配已消除。旧余额不清零、不折损。

普通药按全队总属性削减一次，再按各单位可减容量分摊，保留每单位至少1。替换从原始数值重算，无效果或比旧药弱则拒绝且不扣物品。精魄药仍以绝对百分点扣减，至少一个当前效果进一步下降才可用；两槽无法覆盖所有高层效果，保留选择价值。药效失败后保留、胜利清空。

## 4. 九狱固定难度【B】

保留原表的敌人身份、数量、原始属性形状和28个有精魄的关卡。按各狱固定比例对每个单位四维向下取整、至少1，再把灵力限制在缩放后攻击×2以内，最后应用药品。**敌人不随当前玩家战力变化。**

主冥仙使用原角色可释放的主动技能，技能等级保持原表1；原技能为被动／不可释放时补101。仅主冥仙佩戴层级精魄；守卫仍有各自属性与普攻。这个选择让灵力药有实际用途，同时避免直接将数千万原始灵力代入通用法术公式。原服技能继承和精魄范围仍未知，本地以实测可玩性为目标。

## 5. 实战与资源验收

### 连续通关与入门

[连续通关记录](../analysis/evidence/abyss/progression_repaired_20261028.json)使用未加属性的99级资料库攻击阵容：初始元宝0、银币0、炼药1级、无预置药品／药材；从入门补给开始，实际学习、购材、炼制358次并用药，2,009次原版协议请求完成81层，按每日5次共17个模拟日；第40层重启继续，每条请求均验证原包重复发送不重复扣费／发奖，最终通幽榜第一。第72层达到36级，整个过程中没有额外充值资金或修改战斗结果。

通关时剩余银币28,175,000、魂晶123,413、元宝0；其中魂晶包含跨日挂机。银币是有限首胜收益，留下重炼余量；不代表全游戏经济已完成长期模拟。

[第一狱入门记录](../analysis/evidence/abyss/entry_npc_v2_l75_t5_endurance_20261028.json)使用75级、战力14,460的低档资料库阵容，同样零资金／炼药1级起步，通过9层并进入第二狱。中低战力不能因此无条件通过后狱，后期仍需角色养成。

### 多阵容、多个随机种子

每套阵容使用合法36级可稳定产出的极品药，均不加角色属性、不改敌人、不强制胜负；各层独立挑战，不把预置药模拟写成自然获取过程。三种角色类型各5个种子，共1,215场：

| 阵容 | 配置战力 | 5种种子各自通过层数 |
|---|---:|---|
| npc_v1_l99_t1_attack | 4,446,103 | 81 / 81 / 81 / 81 / 81（均为81层） |
| npc_v2_l99_t1_magic | 2,669,258 | 81 / 81 / 81 / 81 / 81（均为81层） |
| npc_v1_l99_t1_endurance | 3,013,181 | 81 / 81 / 81 / 81 / 81（均为81层） |

另外[810场分层抽样](../analysis/evidence/abyss/regions_repaired_20261028.json)覆盖5套不同战力阵容、不用药／满级药两种方案。最高攻击样本不用药只通过58/81层、首次失败47层；用药后81/81。低档样本满级药也未全部通过，保留养成与药品选择的必要性。

阵容的既有装备与培养来自资料库，上述验证不包括从新手账号养成到99级的时间，17天是已有高阶阵容在本活动每日次数下的最短通关样本，不是所有玩家的承诺。
