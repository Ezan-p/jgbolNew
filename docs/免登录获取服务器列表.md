# 无需渠道登录获取服务器列表

2026-10-23：已直接获取 **258 条**安卓混服区服记录，列表版本 **1263**。

- [可阅读的完整列表](../analysis/server_lists/服务器列表.txt)
- [JSON 数据及来源信息](../analysis/server_lists/server_list.json)
- [下载原文](../analysis/server_lists/server_list.raw.txt)

这份文件通过客户端已有的公开 HTTP 目录取得，不需要渠道账号、token 或登录回调。客户端调用顺序也是先下载列表、再显示选区，选择进入游戏时才调用渠道登录。

## 原因与修正

当前 360 接入的渠道号是 `107 / p360_na`，它构造的列表地址返回 HTTP 404：

`http://jgbupdate02.shangyoo.com/update/jgb/p360_na/server_list.txt`

旧 360 目录 [p360_a/server_list.txt](http://jgbupdate02.shangyoo.com/update/jgb/p360_a/server_list.txt) 返回 HTTP 200，内容与原始 3.87 的 `wdj_a2` 列表逐字节一致，都是安卓混服列表。当前 `p360_na` 配置中另外三个备用地址也已检查：一个 DNS 解析失败，两个连接超时。检查记录：[endpoint-checks.json](../.runtime/server-list/endpoint-checks.json)。

修正版 APK 为 `build/jgbol3.87-360-list.apk`。只在 `lua/update/update_mgr.lua` 的 `downloadServerList` 函数中把列表目录固定为 `p360_a/`，其他函数、渠道号 107 和账号登录逻辑保留。没有伪造登录成功，也没有尝试免认证进入远端游戏服。

实现对一个字符串常量和一条跳转指令做定点修改，并校验全部函数的指令和常量，拒绝未知版本或重复应用补丁。修改源文件：`assets/release_/771ef5cb7d6e7c013cbb305c6fcad41c.data`；原始 `jgbol3.87/` 文件未改动。

## 使用

双击项目根目录的 **获取服务器列表.command**，即可直接更新并打开文本列表，不启动游戏或渠道 SDK。也可以运行：

```sh
.runtime/venv/bin/python fetch_server_list.py
```

读取工具只解析 Lua 字面量表，不执行下载内容；输出保存在 `analysis/server_lists/`。原文与 JSON 保留来源、抓取时间、HTTP 最后修改时间及 SHA-256。

默认 `game.json` 已指向列表修正版，双击 **启动游戏.command** 使用该版本。重新构建：

```sh
python3 build_apk.py
# 或直接指定列表修复变体
python3 build_channel360.py --server-list-compat
```

上一版未修正列表地址的 360 配置保存在 `game.360.json`；原始 UC 配置仍为 `game.uc.json`。恢复上一版默认配置时，复制对应 JSON 为 `game.json`，按配置重新安装，再运行 `restart-web` 即可。

## 数据边界与检查

服务器返回的文件最后修改时间是 **2018-12-24 08:30:44 GMT**。区服名称里的“新服”“爆满”以及数值 `status` 都是原文件内容，不能据此判断当前运行状态。258 条记录包含独立区服 ID，但可以共享登录地址；地址字段也不等于认证后分配的游戏连接地址。

本次没有逐个探测登录服、输入账号或验证进入游戏。独立获取文件成功，不等于这些旧区服仍可登录。

模拟器验证：冷启动返回 `Status: ok`，渠道仍为 107；实际请求已变为 `p360_a/server_list.txt`。未调用渠道登录即显示默认区服，点击“点击换区”成功打开“所有服务器”面板。界面底部仍保留游戏更新的网络提示，本次只修复列表获取，未验证完整更新和进入游戏。
