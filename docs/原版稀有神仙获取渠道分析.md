# 原版稀有神仙获取渠道分析（3.87）

分析日期：2026-10-26。范围为本仓库 `jgbol3.87` 原包、从原包提取的配置及 LuaJIT 字节码；不把离线服赠送、NPC 阵容或本地推测奖池当作官方获取规则。本次没有取得官方服务端运营配置、历史活动公告或实际结算日志。

## 1. 结论

**元始天尊可以明确定位到“两周年庆／元始祈愿”活动；东华大帝可以确认不在高级、超级召唤名单，也不能通过天缘召唤取得首只，但现有原包证据不足以确定它专属的首发或返场活动。** 不能因为二者都不在召唤池，就认定来自同一个活动。

| 神仙 | ID | 原包可确认的获取渠道 | 证据边界 |
|---|---:|---|---|
| 元始天尊 | 5046 | 两周年庆每日祈愿，进度满领取；元始天尊福袋；领取后继续祈愿获得魂魄 | 活动机制和福袋说明明确；具体所需天数、每次进度、供品价格缺失 |
| 东华大帝 | 5048 | 尚未定位到明确绑定它的活动奖项；拥有后可用五星仙界魂兑换其魂魄，天缘挑战也有来源魂魄产出 | 后两项只能补养成魂魄，不能解释首只从哪里来 |
| 王母 | 5027 | 周年庆礼包、活动集市王母礼包、任意充值纪念礼包；另可用东华大帝挑战天缘获得王母魂魄 | 礼包来源和部分内容明确，活动日期、售价等未知 |
| 如来佛祖 | 5053 | 如来转世盘，获得如来大小福袋，开出如来魂魄后合成 | 福袋与活动名称明确；抽奖概率和充值档位未知 |

证据等级：**【A】**原包直接包含的文案、配置或客户端分支；**【推断】**根据这些材料作出的解释；**【未知】**需要服务端配置或历史运营资料才能回答。

## 2. “无法召唤”具体指什么

【A】[summon_cortege_set.csv](../analysis/configs/summon_cortege_set.csv) 分别列出高级和超级召唤的神仙类型，两份名单均没有 `5046`、`5048`。这里可以确定的是“未列入原包高级／超级召唤集合”，不能扩展为“所有历史版本、所有限时召唤都绝不投放”。原服是否曾通过热更新或运营配置调整，需要额外证据。

【A】天缘召唤有另一张有方向的关系表：[convert_output.csv](../analysis/configs/convert_output.csv)。字段依次为来源神仙、目标神仙、奖励。

```text
5046 元始天尊 → 5045 灵宝天尊
5048 东华大帝 → 5027 王母
```

这意味着必须先有元始天尊，才能以其为来源挑战灵宝天尊；先有东华大帝，才能挑战王母。**不能把箭头反过来理解成“王母召唤东华、灵宝召唤元始”。** 原表没有任何一行把元始天尊或东华大帝列为目标。

来源奖励中确实包括来源自身魂魄，但其前提仍是已拥有来源神仙。天缘机制详见[天缘召唤原版规则与离线实现说明](天缘召唤原版规则与离线实现说明.md)。

## 3. 元始天尊：两周年庆的祈愿进度奖励

### 3.1 活动身份与获取流程

【A】原客户端模块名为 `lua/ui/twoYearsCelebrateUI.lua`，请求为 `1334 msg_yuanshi_activity`，参数 `serial_num、flag、index`。它是独立元始活动，不是洞府佛堂祈愿，也不是献祭神仙的祈福。

【A】原包 `v2/String2.plist` 保留以下直接说明，已提取到[证据审计](../analysis/evidence/rare_gods/audit.json)：

| 文案键 | 原文 |
|---|---|
| `twoyears_info10` | 每日祈愿可以提高元始天尊等级，进度满后可以获得等级为主角*2的元始天尊 |
| `twoyears_info23` | 点击人物图像可以获得元始天尊 |
| `twoyears_info24` | 获得元始天尊后，继续祈愿将可以获得元始天尊魂魄 |
| `twoyears_info6` | 当日若未祈愿，玉清阁将增加一份祈愿供品出售 |
| `twoyears_info2` | 当前免费祈愿次数： |

由此可还原玩家流程：活动开放后进入两周年庆，使用免费祈愿次数积累进度；没有免费次数时，可通过祈愿供品增加祈愿机会；进度满后点击人物领取元始天尊；领取后继续参与可获得其魂魄。

【A】字节码与文案一致：`twoYearsCelebrateUI` 原源码行191—207检查 `free_times` 及物品1807，发送 `wish_yuanshi`；行383—529使用服务端返回的 `cur_progress`、`free_times` 等字段绘制主界面。完整反汇编见[twoYearsCelebrateUI.txt](../analysis/evidence/rare_gods/twoYearsCelebrateUI.txt)，其中 `[Lxxx]` 是字节码保留的原源码行号。

### 3.2 供品和福袋

【A】[item_name.csv](../analysis/configs/item_name.csv) 明确记载：

| 物品 | ID | 原版说明 |
|---|---:|---|
| 祈愿供品 | 1807 | 向元始天尊供奉，可以额外进行一次祈愿；来源为活动期间产出 |
| 元始天尊福袋 | 1808 | 打开获得等级为主角等级×2的元始天尊；来源为活动期间产出 |

两条证据分别证明“进度领取”和“福袋开启”均存在。**目前不能只凭这两条就断言进度满必定先发1808福袋，也不能断言福袋只由这个活动产出。** 客户端文案承诺的神仙等级相同，具体发奖形式由服务端决定。

### 3.3 是否必须充值

【A】活动还包含充值激活礼包的分支，文案涉及任意充值、30元、50元，以及领取已激活礼包。它与免费祈愿次数、祈愿供品和进度是不同字段与操作。

因此，可确定“活动有免费祈愿，也有充值礼包”；不能据此宣称“必须充值才能拿到元始”，也不能在缺少活动时长和进度表时承诺“零充值必定能在一期内领到”。

【未知】活动总天数、每日免费次数的具体值、单次增长进度、漏签补领价格、领取后每次魂魄数量、重复领取处理。以上参数不应从当前离线服自行补出的数字倒推。

## 4. 东华大帝：首只渠道尚缺运营证据

本次交叉检查了原包神仙表、召唤集合、完整天缘关系、物品名称与来源、原包文本中的姓名，以及活动模块的奖励接收方式。

【A】可以确认：

1. `5048` 是可养成的五星神仙，并有转生配置；不是只有剧情形象的角色。
2. 高级、超级召唤集合都没有它。
3. 天缘关系中只有“东华大帝→王母”，没有任何来源指向东华大帝。
4. 物品表没有找到直接点名东华大帝的礼包说明，不能像元始、王母、如来一样建立“活动名称→专属道具→角色”的明确链条。
5. 原包存在服务端下发奖励的通用运营入口。例如 `promotionUI` 通过1217查询累计消耗元宝奖励，再通过1218领取，界面读取 `prize_info/prize_list`，奖项并非全部写死在客户端。见[promotionUI.txt](../analysis/evidence/rare_gods/promotionUI.txt)。

【推断】东华大帝的首只可能由这类运营投放、礼包、兑换或其他动态奖励提供；但“存在这种机制”不能证明“东华一定来自累计消费活动”。同样没有依据把它直接归给充值排行、九重天、封神榜或两周年庆。

要锁定活动，最有效的补证是原服活动公告、带奖励名称的截图，或者服务端返回的奖项列表；列表中的奖励对象必须是神仙5048，或其魂魄／可开出它的礼包。单独出现数字5048不够，必须核对对象类型和字段含义。

## 5. 界魂兑换为什么不能解释首只来源

【A】[adaptive_spirit_convert.csv](../analysis/configs/adaptive_spirit_convert.csv) 中包含元始天尊和东华大帝，两者 `need_count=1`。这说明存在界魂兑换配置。

但原包说明 `soul_ex_tip1` 明确写着：

> 界魂可以转换为自己拥有的同星级、同类型神仙的魂魄

因此，五星仙界魂是这两位神仙的**后续魂魄补充渠道**，不能据此得出“攒40个仙界魂就能直接解锁未拥有的东华大帝”。兑换还涉及活动开放状态与银两费用，不能把 `need_count=1` 理解成无条件免费兑换。字节码见[soulExchangeUI.txt](../analysis/evidence/rare_gods/soulExchangeUI.txt)。

【A】直接获得指定神仙魂魄则是另一回事：[cortege_quality.csv](../analysis/configs/cortege_quality.csv) 规定五星神仙合成需要40魂魄。因此活动若直接发放东华魂魄，可以形成首次合成渠道；本次缺少的是“哪个活动实际投放这些魂魄”的绑定证据。

### 如来佛祖：如来转世盘

【A】物品1367“如来小福袋”和1368“如来大福袋”来源明确为“如来转世盘活动产出”。详细说明分别为5个、20个如来魂魄，也可以转化成50个、200个五法界魂箱。

原包 `turntable_5` 说明充值达到指定额度可获得转盘机会，随机得到道具；达到指定充值档次还有额外豪礼。由此可确认这是含充值门槛和随机奖励的运营活动，不是普通召唤。

原表1368存在文案不一致：长说明为20魂魄／200箱，短说明误沿用5魂魄／50箱。本文保留长说明记录，但实际原服发奖数量仍以服务端结算为准；不能把短说明矛盾隐去。缺少奖池和概率，无法计算获得一只如来的准确花费。

## 8. 排除容易混淆的证据

- **NPC拥有不等于玩家能获得。** `analysis/npc_design` 的阵容是本地设计；副本、九幽和猎魂首领配置表示战斗对手，不能当作掉落表。
- **剧情援军不等于赠送。** 开场剧情中东华、元始出场只证明剧情使用该角色。
- **封神榜积分数值不是礼包ID。** `top_score.csv` 某行的1808位于 `day_score` 列，是每日积分；不是物品1808元始福袋。现有 `top_score_exchange.csv` 也没有两位神仙的指定奖励。
- **离线开服邮件不是原版渠道。** 本地开服礼包、调试发放和直接修改存档，只能解释当前账号为什么有该神仙。
- **界魂物品与神仙编号会重号。** 例如物品5001是五星仙界魂，神仙5001是阎罗王；检索必须结合对象类型。
