## 2. 装备属性公式与原版数值

设基础值为 `b`，原表每级成长为 `g`，强化等级为 `L`。当前原表三类封神装备均为成长增加 12%。

```text
普通装备基数 B = b + (L−1) × g
封神装备基数 B = b + (L−1) × g × 1.12
已有六星状态（star_level=1）的基数再乘 2

装备直接属性 = floor(B)
             + floor(B × 所有镶嵌灵石系数之和)
             + floor(B × 当前进阶系数 + 当前进阶固定值)
             + floor(B × 当前铸造系数 + 当前铸造固定值)
```

【A】这四项来自原版 `packageUI:1582–1594`；灵石单孔预览来自 `stoneUI:475–495`。进阶和铸造都使用当前档位的累计值，不能再把历史每档相加。

【B】完整神仙乘区已明确为配置策略，见第5节；原包没有服务端结算顺序，采用该策略不表示整个神仙面板已获原服认证。

### 开孔、镶嵌、卸下

原客户端默认开放等级 10，品质 1–5 默认孔位上限分别为 1／1／1／2／3，已有六星状态增加一孔，协议最多四孔。开孔使用道具 1093。装备只能镶嵌对应类型灵石；卸下保留灵石等级、ID、失败补偿和锁定状态。已有灵石的孔位必须先卸下；禁止用已镶嵌灵石作为材料。

【B】服务端开放等级采用客户端默认 10；每次开孔扣 1 个 1093；镶嵌和卸下不收费。后两项没有取得原服收费快照。

### 普通升级

【A】客户端预览概率为 `材料价值之和 ÷ 当前等级 cost + prob_compen/100`；银币消耗读取当前等级 `silver_cost`。1–9 级分别为 1万／3万／5万／10万／30万／60万／80万／100万／200万。10 级及以上在原界面转入升华／提炼。

【B，用户授权】服务端采用上述概率并封顶100%，百万分之一随机精度；每次消耗选中 ID 各一个灵石及银币。失败等级不变，累计增加 **5 个百分点**补偿，最多100%；成功升一级并清零补偿。普通材料限制为未镶嵌、未锁定的 1–10 级灵石，允许跨类型贡献原表价值。此失败补偿、材料筛选策略与随机精度是可调整推测，**5% 不应被引用为原版结论**。

例如 1 级目标 `cost=2`，一个 1 级材料 `worth=0.8`，基础概率 40%；失败后补偿5%，下一次同等材料为45%。三个 1 级材料达到100%。

### 升华与提炼

【A】10→11：额外消耗同类型10级灵石一个；武器／防具再扣补天石1333×3，法宝扣×5。11→12：额外消耗同类型11级灵石一个；武器／防具再扣1369×3，法宝扣×5。**目标本身不算额外材料**，不能拿低级堆叠数量顶替同等级材料。

原客户端 11→12 要求主角四重境界。【B】升华权益从一重境界开放；固定材料操作必成，不额外收费，成功清零普通升级补偿。入口与后端共用配置中的 `reborn_min_realm`。

所有请求先在临时角色副本中结算，回复可序列化后再写数据库。材料不足、孔位错误、类型不符、重复材料 ID、目标充当材料、锁定材料、已镶嵌材料、位置过期、境界不足均拒绝且不扣资源。同一请求序号与内容重放直接返回已缓存结果，不重复抽概率或扣材料。

完整属性阶段由配置声明并校验，计算结果在 `combat_power_breakdown.attribute_policy` 与各神仙阶段小计中可复查：

1. 原表基础＋等级成长＋培养固定值；再加飞升成长（每级成长×3先取整，再乘飞升次数）。
2. 加三件装备直接属性；被动法术百分比合并后乘算。
3. 神仙转生累计百分比，再加方向固定值与仙脉；封神套装乘算，再加对应装备连锁。
4. 觉醒固定值、星魂五行固定值、星魂阵容属性；战斗条件触发属性仍在战斗处理。
5. 以上对应属性乘 `1＋仙缘百分比＋进阶第三字段百分比`。
6. 向下取整，加收藏、主角全队固定值和洞天生命；再加称号。
7. 洞天训练百分比及固定值、上阵灵兽、助阵、显式战力来源依次计算；最终向下取整并限制协议整数范围。

助阵采用两遍计算：只读取助阵神仙在第5步后的值，避免读取上次缓存面板产生反复放大。精魄评分使用既有V1.1规则，在战力评分阶段处理，不伪装成永久四围。该顺序作为稳定本地策略沿用并显式化，避免仅因“补配置”再次改变已有培养结果。
