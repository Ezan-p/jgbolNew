# 太虚幻境血战离线玩法说明

更新日期：2026-10-27。适用：本仓库3.87客户端及当前离线后端。配置版本：`offline-taixu-3`。

本文单独介绍太虚幻境中的「血战」，包含完整流程、时间限制、刷新条件、挑战次数、排名、奖励，以及与原版的区别。历劫关卡及开发修复记录见[太虚幻境历劫与血战离线实现说明](太虚幻境历劫与血战离线实现说明.md)。

## 1. 规则标记与玩法概览

- **【A】原版可确认规则：** 原包玩法手册、客户端逻辑或配置表能够确认的内容。原包文案与配置存在差异时，分别注明证据范围，不把它们直接当作原服最终执行规则。
- **【B】离线补全规则：** 缺少原服务端资料时采用的推测、离线模拟，以及本项目按需求进行的主动调整。【B】不表示尚未实现，而是不能宣称为官方规则。

**当前血战是一项由玩家手动推进、跨日保留进度的离线赛事。各阶段和整届比赛都没有服务端强制结束期限；北京时间零点不会直接清空比赛，也不会补满挑战次数。只有结算旧届后，满足日期条件，才能开启新届。【B】**

完整流程：

**冲榜 → 练习赛 → 血战第一阶段 → 血战第二阶段 → 血战第三阶段 → 结算本届**

上述阶段结构来自原版【A】；手动推进、具体次数和每日新开一届的机制属于离线规则【B】。

## 3. 各环节流程

| 环节 | 当前离线玩法 | 如何推进 | 时间限制 | 与原版的关系 |
|---|---|---|---|---|
| 冲榜 | 10次免费挑战，按积分排名；本届首次击败每名对手获得20仙晶 | 至少完成1场，点击「进入练习赛」 | 无服务端阶段截止时间 | 【A】有冲榜与晋级资格；【B】次数、仙晶奖励及手动推进 |
| 练习赛 | 5次免费挑战，不改变积分和赛事血量，不发额外战斗奖励 | 至少完成1场，点击「进入血战一」 | 不必等待现实中的第三天 | 【A】有练习赛；【B】5次额度及具体结算方式 |
| 血战第一阶段 | 9行动力，每场消耗3点；胜利加100分、对手扣20血；失败自己不扣血 | 至少完成1场，点击「进入血战二」 | 无服务端阶段截止时间 | 【A】第一阶段进攻失败不扣血；【B】行动力、积分与扣血数值 |
| 血战第二阶段 | 重新获得9行动力；战斗规则同第一阶段 | 至少完成1场，点击「进入血战三」 | 无服务端阶段截止时间 | 【A】第二阶段进攻失败不扣血；【B】具体数值及推进方式 |
| 血战第三阶段 | 重新获得9行动力；胜利加100分、对手扣20血；失败自己扣20血 | 至少完成1场，点击「结算本届」 | 无服务端阶段截止时间 | 【A】第三阶段进攻失败扣血；【B】扣20血及手动结算 |
| 结算 | 按最终排名发元宝、圣母蟠桃，弹出「获得奖励」窗口 | 本届只结算一次 | 不按倒计时自动发奖 | 【A】有排名奖励；【B】当前奖励组合与发放时点 |

推进时需要注意以下离线规则【B】：

1. 每阶段要求的是**完成战斗，不要求获胜**。
2. 可以打满本阶段免费额度，也可以只打一场就推进。
3. 提前推进后，剩余额度不会结转，不能回到前一阶段补打。
4. 自己赛事血量为0时，允许不再战斗而继续推进，避免卡住。
5. 只能推进自己分组的未结束赛程。
6. 尚未结算时，退出游戏、重启或跨日均保留当前进度。

右上角的推进操作使用带边框、背景和按下效果的按钮。未完成本阶段首场挑战且赛事血量仍大于0时，按钮置灰；完成一场或血量耗尽后可用。结算后不再显示阶段推进按钮。【B】

正常情况下，一届有**24场免费挑战：冲榜10场＋练习5场＋三段正式赛各3场**。如果每阶段只打一场，则5场即可走到结算。【B】

## 4. 冲榜积分、晋级与初始血量

原版说明明确写有：排行榜前列获得血战资格，并按名次下发血量和分数。【A】

当前离线实现采用以下具体规则【B】：

- 玩家从0分开始冲榜；NPC带有预设初始积分。
- 胜利后的积分取以下两者中的较大值：**自己的原积分＋100**、**本次对手积分＋1**。
- 冲榜失败不扣积分。
- 同一对手可以重复挑战；首次击败奖励每届只给一次。
- 当前配置为20名参赛者、20个晋级名额，因此所有参赛者均可晋级。冲榜的主要作用是争取初始血量及首次击败奖励。
- 从冲榜进入练习赛时，一次性按冲榜名次分配赛事血量。

初始赛事血量公式【B】：

`初始血量 = 100 + (20 - 冲榜名次) × 5`

| 冲榜名次 | 初始赛事血量 |
|---|---:|
| 第1名 | 195 |
| 第5名 | 175 |
| 第10名 | 150 |
| 第20名 | 100 |

积分沿用冲榜结果，当前没有额外增加一套晋级积分奖励。进入后续正式阶段时，只重置行动力，**不会重新补满赛事血量或清零积分**。【B】

排行榜中的「赛事血量」与单场战斗中神仙的生命值是两套数值。当前赛事扣血由胜负固定结算，不按动画中损失了多少生命值来扣。【B】

## 5. 正式血战排名与挑战范围

正式赛的排序原则是：**赛事血量高者优先；血量相同，再比较积分。**【A】两项完全相同时，以稳定身份顺序打破平局。【B】

当前挑战范围沿用原客户端的五人名次档判断【A】：

- 自己第8名，可挑战范围到第10名，排除自己。
- 自己第3名，可挑战范围到第5名，排除自己。
- 服务端会检查目标身份、当前名次、所属分组和比赛阶段。【B】

正式血战还要求自己和对手的赛事血量都大于0；血量耗尽的对象不能再被挑战。【B】

主动挑战使用NPC的实际阵容及现有战斗引擎计算胜负，包含已接入的装备、法术、精魄和觉醒效果，不接受客户端自行上报胜负作为结算依据。【B】

单场战斗另有战报动作及事件容量上限，未在安全上限内分出胜负的结果不算胜利。这属于战斗引擎限制，不是某个赛事阶段或整届比赛的现实时间限制。【B】

## 6. 次数、行动力与付费补战

以下具体额度及恢复方式均为当前离线规则【B】：

| 项目 | 额度或消耗 | 恢复或重置方式 |
|---|---|---|
| 冲榜 | 10次免费挑战 | 新届重置；本届跨日不补满 |
| 练习 | 5次免费挑战 | 进入练习阶段获得；本阶段跨日不补满 |
| 正式赛 | 每阶段9行动力，每场消耗3点 | 每进入一个正式阶段重置为9点，不按分钟恢复 |
| 付费补战 | 免费次数或行动力不足后，每次20元宝 | 整届最多5次，各阶段共用；新届重置 |
| 体力、精力 | 血战挑战本身不额外扣除 | 不适用 |
| 历劫神仙次数 | 血战不占历劫每神仙每日4次额度 | 两个玩法分别计算 |

**等待、刷新、重登、跨日都不会补满同一届当前阶段的额度。**

免费额度尚有剩余时，即使请求带付费标记，服务端也不会扣元宝。免费额度耗尽后，可以直接推进，也可以经客户端确认使用付费补战。【B】

理论上，24场免费挑战之外最多再增加5场，合计29场主动挑战；前提是仍有合法且存活的可挑战对象。付费额度不是每阶段5次，也不是每天零点刷新5次。【B】

原客户端存在付费挑战及赌斗相关操作。【A】当前20元宝、整届5次的数值属于离线配置，**赌斗未开放**。【B】

## 7. 阶段时间、整届时间与刷新条件

### 7.1 各阶段和整届是否限时

当前服务端没有阶段截止时间，也没有整届最长持续天数。只要未结算，可以把同一届分多天完成。【B】

**太虚幻境的72小时限制属于「历劫」大关，不属于血战。**历劫的72小时规则可以在原包手册中确认。【A】

为兼容原版界面，血战响应仍包含阶段起止时间，但这些字段不是离线赛事的真实有效期。服务端不因倒计时自动推进或结算；练习赛面板改为显示「可直接推进」，并取消原每秒刷新轮询。【B】

如果长期停留旧页面出现倒计时过期，可重新进入获取当前阶段显示；不能把这个显示理解成服务端已经自动晋级、发奖或清空比赛。【B】

### 7.2 新一届何时开启

日期按**北京时间00:00**划分。服务端在处理血战请求时，按以下条件建立新届【B】：

`没有旧届，或者（旧届已经结算，并且当前日期晚于旧届开赛日期）`

| 情况 | 实际结果【B】 |
|---|---|
| 今天开赛，今天结算 | 今天不能再开第二届；次日零点后再次进入可开新届 |
| 昨天开赛，今天结算 | 结算后再次进入即可开今天的新届，不必额外等24小时 |
| 一届打了三天仍未结算 | 保留原阶段、积分、血量、剩余次数和名单 |
| 好几天没有登录 | 不自动结算，不累计补发多届参赛机会 |
| 到了零点仍停在旧届 | 不强制换届；满足条件后的下一次血战请求才创建新届 |
| 今天先完成昨天旧届，再完成今天新届 | 可以，但今天仍只新开了一届 |

因此，准确说法是：**每天最多新开一届，不是每24小时刷新一次，也不是每天零点强制重置。**【B】

### 7.3 哪些内容会刷新

| 内容 | 什么时候变化或重置【B】 |
|---|---|
| 本届参赛名单 | 新届重新按日期和组别生成，本届固定 |
| 自己的等级分组 | 新届按当时等级确定 |
| 阶段战斗次数 | 推进到下一阶段时重置阶段计数 |
| 正式赛行动力 | 进入每个正式阶段时重置为9点 |
| 赛事血量 | 冲榜结束时分配，后续随战斗变化，不按阶段补满 |
| 冲榜首次击败记录 | 新届清空 |
| 整届付费补战额度 | 新届恢复为最多5次 |
| 积分、历史战报与结算快照 | 新届重新建立，旧届不继续累计 |

## 8. NPC互动与离线排名变化

NPC的主动挑战与自动配对采用两种处理方式【B】：

- **玩家主动挑战NPC：** 使用实际阵容运行战斗引擎。
- **NPC之间配对：** 从血战一推进到血战二、从血战二推进到血战三时，存活NPC各进行一轮配对；按固定阵容战力判断胜负，胜者加分、败者扣血。

这些配对不会攻击玩家。挂机、退出游戏或等待期间，不会出现NPC持续偷袭、扣玩家赛事血量或资源的情况。最后点击「结算本届」时，不再额外进行一轮NPC配对。【B】

因此，当前离线版的竞争强度、血量消耗及排名变化，不等同真人服务器中的玩家互相攻击。

## 9. 奖励与领取方式

### 9.1 冲榜首次击败奖励

冲榜阶段，本届首次击败每名NPC获得20仙晶。重复击败同一目标仍可增加积分，但不重复给仙晶；新届清空首次击败记录。【B】

练习及正式血战没有额外的每场物品奖励。当前也不在冲榜结束时另发一套阶段排名奖。【B】

### 9.2 最终排名奖励

当前本届最终奖励如下【B】：

| 最终名次 | 元宝 | 圣母蟠桃 | 本届声望记录 |
|---|---:|---:|---:|
| 第1名 | 500 | 10 | 1,000 |
| 第2—3名 | 400 | 8 | 800 |
| 第4—10名 | 250 | 5 | 500 |
| 第11—20名 | 150 | 3 | 300 |

点击「结算本届」后，服务端在同一次结算中发放奖励，并用原版「获得奖励」窗口展示元宝、圣母蟠桃及数量。弹窗用于展示和确认，关闭窗口不会再发一次，重新进入也不能重复领取。【B】

确认奖励后，点击结算榜单右上角关闭按钮，直接返回四组血战入口，不再露出第三阶段的旧挑战页面。【B】

声望当前只记作本届活动统计，没有接入角色道行，也没有声望商店。新届不会在上一届声望上持续累计。【B】

### 9.3 原版奖励证据的范围

原包资料存在以下不同表述，需分别看待：

- 【A】血战文案 `arena2` 写有「冲榜会有元宝和圣母蟠桃奖励」。
- 【A】通用表 `all_rank_prize.csv` 列出了上述名次、数量与声望档位，但道具为**蟠桃（1001）＋贡献令（1029）**。
- 【B】当前实现按既定需求，统一在最终排名结算时发放**元宝＋圣母蟠桃（1343）**，冲榜首次击败另发20仙晶。

仅凭原包文案和通用表，不能确认原服各阶段、各分组最终采用哪套发奖方案。当前奖励组合、发放时点及首次击败规则不能整体宣称为原版还原。

依据：[原包奖励表](../analysis/configs/all_rank_prize.csv)、[原包道具名称](../analysis/configs/item_name.csv)、[原包血战文案](../jgbol3.87/assets/release_/08b0428edce64d19f304d30c3829ec87.data)、[离线奖励配置](../server_config/taixu_rules.json)。

### 10.2 主要差异对照

| 项目 | 原版可确认内容【A】 | 当前离线处理【B】 |
|---|---|---|
| 赛事结构 | 冲榜、练习、三段血战 | 保留阶段结构，玩家点击按钮推进 |
| 开放与休战 | 有现实日期、时段和休战安排；入口另有月内开放提示 | 取消现实等待和休战，未结算赛事跨日保留 |
| 参赛资格 | 排行榜前列取得后续资格 | 当前20人、20个名额，均可晋级 |
| 分组 | 七个等级组 | 删除前三个低等级组，仅保留50—99级四组；20人规模由离线配置确定 |
| 正式赛排名 | 血量优先，其次积分 | 同分同血使用稳定身份顺序 |
| 进攻失败扣血 | 前两阶段不扣，第三阶段扣 | 第三阶段每次扣20血 |
| 初始血量与分数 | 按冲榜名次分配 | 血量使用固定公式，积分沿用冲榜 |
| 次数与付费 | 客户端存在挑战额度和付费操作 | 10次冲榜、5次练习、每段9行动力、每届5次20元宝补战 |
| 赌斗 | 客户端有相关分支 | 未开放 |
| 对手互动 | 原玩法面向玩家赛事 | 改为NPC；仅指定推进节点模拟NPC配对，不离线偷袭玩家 |
| 奖励 | 原包文案与通用奖励表存在不同内容 | 使用当前统一榜奖及首次击败仙晶方案 |
| 换届 | 不能仅凭现有资料确认原服完整周期 | 每天最多新开一届，须先结算旧届 |

## 11. 阵容查看、战报与界面行为

原客户端支持查看对手阵容及历史战报。【A】当前离线规则为【B】：

- 保留本届最近10场主动挑战战报，超出上限淘汰最早记录。
- 已保存战报包含阵容、动作及效果事件，重启后仍可回放。
- 回放不重新计算战斗、不扣次数、不发奖励。
- 结算后至下一届开启前仍可查看本届历史；新届开始时清空。
- 挑战结束后直接恢复当前冲榜、练习或血战面板。
- 顶部不再显示「本地NPC」，对手卡片不再显示「本地离线」；文字调整不改变NPC对手机制。
- 结算使用原版奖励窗口展示本次实际获得的奖励。

上述界面调整已写入客户端补丁。四组入口、推进按钮状态、五阶段返回及结算榜单关闭路径通过Lua5.1隔离回调回归；本次原客户端检查未找到模拟器设备，尚未完成当前版本的实机视觉验收。后端战斗、奖励与回放验证范围见[实现与修复记录](太虚幻境历劫与血战离线实现说明.md)。
