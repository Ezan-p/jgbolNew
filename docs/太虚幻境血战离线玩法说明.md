# 太虚幻境血战离线玩法说明

更新日期：2026-11-13。配置版本：`offline-taixu-8`。

详细名单：[各等级组NPC名单及战力明细](太虚幻境血战各等级组NPC名单及战力明细.md)，包含四组固定前15名及2026-11-09赛周补充席位的身份、战力与阵容来源。

在太虚幻境「历劫／血战」主界面，点击左上角绿色问号右侧的 **血战规则**，可查看「玩法流程」「活动时间」「奖励说明」三个页签。

**当前血战每周开放一届，北京时间周一00:00统一重置。上周未完成的比赛也会清空并重新开始。冲榜、练习及三段正式血战，每次胜利均获得100仙晶；最终排名奖励为元宝、圣母蟠桃和仙晶，不再记录声望。**

本文说明当前离线规则【B】。原版可确认的阶段结构、血量优先排名及前两段进攻失败不扣血标为【A】。离线次数、奖励、NPC模拟和每周刷新机制属于用户指定或本地补全，不代表原服规则。

## 1. 参与条件与玩法流程

50级开放血战，分为50—59、60—69、70—79、80—99级四组；内部组号保留4—7。本组为自己加19名离线对手，共20人。其他组可查看排行和阵容，不能跨组挑战。【B】

新版极高战力NPC只进入80—99级组。它们的**角色等级为99级**，神仙最高600级、499次飞升，不把神仙等级当成角色等级，也不降级塞入低等级组。【B】

| 等级组 | 初始第1—15名NPC | 第16—19名NPC | 含自己的总人数 |
|---|---|---|---:|
| 50—59 | 本地正式NPC库中50—59级战力最高的15名 | 剩余普通NPC分段抽4名 | 20 |
| 60—69 | 本地正式NPC库中60—69级战力最高的15名 | 剩余普通NPC分段抽4名 | 20 |
| 70—79 | 本地正式NPC库中70—79级战力最高的15名 | 剩余普通NPC分段抽4名 | 20 |
| 80—99 | 本地正式NPC库中80—99级战力最高的15名（当前均为E1） | 普通NPC分段抽4名 | 20 |

各组按角色等级范围筛选，在该范围的全部正式NPC中按战力从高到低固定选取15名，使用其真实姓名、玩家ID和完整养成。同战力按NPC编号确定稳定顺序。前15名不再按周抽换；本地NPC库不变时，每周都由相同15名占据初始前列。其余4名从排除这15名后的普通T档池中按绝对战力分成4段，每段确定性抽取1名，保留挑战梯度，同周不变、跨周可能更换。比赛开始后名次仍按积分和赛事血量变化，不锁定NPC最终名次。【B】

本次更新保留已开赛的本组名单、阶段、积分、血量、次数和战报；未开赛的新届直接使用新分配，已有赛程等下周重开时使用。不强行重开或重复发奖。具体分配与验证见[实现说明第15节](太虚幻境历劫与血战离线实现说明.md#15-2026-11-10-各等级组固定接入最强15名npc)。【B】

**冲榜 → 练习赛 → 血战第一阶段 → 血战第二阶段 → 血战第三阶段 → 结算本届。**阶段结构来自原版【A】，离线版由玩家手动推进【B】。

| 阶段 | 免费额度 | 积分与赛事血量 | 胜利奖励 |
|---|---|---|---|
| 冲榜 | 10次 | 胜利后积分取「原积分＋100」与「对手积分＋1」中的较大值，失败不扣分 | 每次100仙晶 |
| 练习 | 5次 | 不改变积分或赛事血量 | 每次100仙晶 |
| 血战一 | 9行动力，每战3点 | 胜利＋100分、对手－20血；进攻失败不扣血 | 每次100仙晶 |
| 血战二 | 重新获得9行动力，每战3点 | 同第一阶段 | 每次100仙晶 |
| 血战三 | 重新获得9行动力，每战3点 | 胜利＋100分、对手－20血；进攻失败自己－20血 | 每次100仙晶 |
| 结算 | 第三阶段完成后手动结算 | 按血量优先、积分其次排名 | 按最终名次一次性发放三项奖励 |

每阶段至少完成一场即可点击右上角按钮推进，不要求获胜；自己的赛事血量为0时也允许推进。提前推进不保留剩余次数，不能返回前一阶段补打。未满足条件时推进按钮置灰。【B】

进入本组参赛后，应完成冲榜、练习及三段血战，再按实际排名结算。冲榜、练习或任一正式血战阶段中点击关闭，会弹出「确认退出本届血战？」面板，提示退出按最后一名（第20名）结算，奖励为300元宝、10个圣母蟠桃和5000仙晶，确认后本周不能再次参赛。选择「继续血战」关闭提示并保留当前进度；选择「确认退出并结算」后，由服务端结算成功再退出，保留已经获得的战斗奖励。【B】

仅打开分组选择页、关闭其他组的查看榜单，或关闭已结算榜单，不触发弃赛结算。已经参赛后退出整个血战入口仍须确认。断线、关闭游戏等没有点击退出的情况继续保留未结算进度，重登后可继续本届。【B】

正常一届最多24场免费主动挑战：10＋5＋3＋3＋3；每阶段只打一场则5场可完成一届。免费额度耗尽后，可经确认每次花20元宝补一战，整届最多5次，各阶段共用。尚有免费额度时不扣元宝。不开放赌斗，血战不消耗历劫神仙上场次数。【B】

## 2. 活动时间与每周重置

一周指 **北京时间周一00:00至下周一00:00之前**。每周只能开启一届，本周内可随时进入、战斗和推进，不需要等待原版的周三、周五或周六时段。【B】

| 情况 | 当前处理 |
|---|---|
| 本周首次进入 | 建立本周比赛，从冲榜开始 |
| 中途点击退出并确认 | 按第20名结算并发奖，本周不能再次参赛 |
| 取消退出，或同周断线、重登、跨日 | 保留本届阶段、积分、血量、名单和剩余额度 |
| 同周已结算后再次进入 | 查看本届结果，不能再开第二届 |
| 到下周一00:00，上届已结算 | 开启新一周比赛 |
| 到下周一00:00，上届只打了一半 | 同样清空旧赛程，从新一周冲榜重新开始 |
| 连续多周没有进入 | 直接开启当前周，不补开过去的比赛 |
| 旧页面跨周后提交挑战、推进、退出结算或战报回放 | 返回新届入口，不执行旧操作，不扣新届次数或费用 |

周边界由服务端时间判定。进入或操作血战时应用当前周状态；无需保持在线，也不会因为上届没结算而推迟新周刷新。服务端拒绝回拨到早于存档的时间。【B】

周刷新重置：阶段、积分、赛事血量、免费挑战、行动力、整届付费补战次数、对手名单、历史战报、结算快照及浏览组。本周参赛组按当时角色等级重新确定；本届内升级不换组。前15名按组别固定选取最强NPC，其余4名按周抽取；本周内不因刷新或临时强化阵容而变动，新周仍保留最强15名，其余席位可能重复。【B】

**请在下周一00:00前点击「结算本届」。上周未结算的排名奖励不自动补发。已经到账的元宝、圣母蟠桃和仙晶不会因周刷新被收回。**【B】

同周普通零点不补挑战次数或行动力；推进阶段只重置新阶段额度。兼容原版界面的倒计时不自动推进或结算，整届仍以周一刷新为截止。历劫的72小时限制不适用于血战。【B】

## 3. 每场胜利奖励

冲榜、练习和三个正式血战阶段中，**每次主动挑战获胜都发100仙晶（道具1366）**，重复击败同一对手照常发放，免费战和付费补战一致。失败、平局或未分出胜负不发奖；回放历史战报不重新发奖。【B】

胜负由服务端战斗引擎计算，不接受客户端自报结果。请求重传不会再次扣次数或发放奖励。仙晶在战斗结算时进入背包，并包含在战斗奖励中。【B】

| 第2—3名 | 800 | 100 | 15,000 |
| 第4—10名 | 500 | 50 | 10,000 |

点击「结算本届」后一次性发放三项奖励，原版奖励弹窗显示实际到账物品。关闭弹窗不影响到账；刷新、重登或再次点击不能重复领取。排名奖与每场胜利的100仙晶分别计算。【B】

最终排名不再发放、显示或保存本届声望记录，也不改变角色道行。更新前已经结算的本周比赛不重复发奖或追溯补发；同周未结算比赛保留进度并使用新奖励。旧档若属于上周或更早，按周规则重新开始。【B】

## 5. 排名、对手和战报

原版冲榜名次影响晋级和初始血量【A】。当前20名参赛者全部可晋级；初始赛事血量为 `100＋(20－冲榜名次)×5`，第1名195血、第20名100血。积分沿用冲榜结果，进入后续血战阶段不补满血量。【B】

正式赛按赛事血量降序、积分降序排名【A】，同分同血按稳定身份顺序打破平局【B】。赛事血量与单场战斗中神仙的生命值不同。

可挑战范围沿用当前名次所在五人档及前方对手：第8名可挑战至第10名，第3名可挑战至第5名，排除自己。正式赛双方赛事血量都必须大于0。服务端核验对手身份、名次、组别及阶段。【B】

玩家主动挑战使用对手实际阵容和八人战斗引擎。由血战一推进到二、由二推进到三时，存活NPC进行一轮离线配对，胜者加分、败者扣血；这些配对不攻击玩家，挂机和退出期间不会持续偷袭或扣资源。【B】

保留本周最近10场主动挑战战报，重启后可回放；回放不重新计算战斗、不扣次数、不发奖励。超出10场上限或跨周清空后的战报不可继续回放。结算后至周刷新前仍可查看本周战报。【B】

## 6. 原版与离线规则的范围

原包手册写有周三至周四冲榜、周五练习、周六三段正式血战与休战；入口另有「每月第二周第三天开启血战」文案。缺少原服配置，不能据此推断原服固定每周一重置。【A】

当前每周一重置、100仙晶胜利奖、最终元宝＋圣母蟠桃＋仙晶榜奖均为用户指定的离线规则【B】。原包通用排名表含蟠桃、贡献令及声望字段，不修改该证据表，也不将当前奖励宣称为原服规则。
