## 【A】原版客户端合同

### 位置、开启与目标

1. `cheer_order_index` 定义正八卦 1–8：乾、坤、震、巽、坎、离、艮、兑；逆八卦 9–16 为对应逆位。UI 通过 `index + orientation * 8` 发包（L948–955）。
2. 配置段为 `g_new_config[14]`。字段为 `is_open`、`is_open_ni`、`cheer_level_limit`、`open_cheer_item`、`cost_item_count`、`cost_gold_count`（L490–499）。等级及开位道具按全局位号索引；洗炼两项消耗是**数值**，不是表。
3. `is_open_ni` 参与整数比较；1 表示逆位基础功能，2 才开放进一步培养／法术等（L89–96）。不能发送布尔 `false` 代替整数。
4. 正八卦前两位无论等级字段是否为零都直接进入；第三位起使用开位提示。正位第4位起、逆位第3位起检查前方阵位已经开启（L865–902）。前两位何时由原服务端赋初始等级无法仅凭客户端确定。

6. 助阵候选必须 `order=0` 且 `cheer_order` 为空／0（L638–648）。选择加成目标发神仙 ID；显示时用角色 `cheer_<方向>_effect` 索引**上阵位置**（L686–700、L2789–2799）。并非固定对相同编号阵位生效。
7. 查看阵容 `owner_cheer_info` 使用**数值属性编号**；`cheer_cortege` 按助阵位置索引。查看界面再将其映射为角色属性和助阵神仙（checkLineupUI L52–67、L174–187）。

## 【B】补齐的服务端规则

- 2026-11-13按本次确认的原版开放设计调整：40级解锁八卦后，乾、坤直接进入，服务端自动设为1级，不消耗八卦令；震、巽、坎、离、艮、兑统一需60级，再消耗开位材料依次开启。达到60级不会自动解锁后六位。逆八卦8位仍为60级。此前42／44／46／48／50／52级逐位开放方案已被替代。

### 数值、目标与战斗

- 正位逐级累计原CSV的 `*_plus`。逆位缺少独立表，暂复用同编号正位。`recover` 列保留原证据，但本地公式不据此生成额外资源或战斗回血。
- 每个助阵位只选一名助阵神仙、一个受益神仙；同名神仙不能同时出现在主阵或其他助阵位。2026-11-13起，正逆八卦16位共同实行一对一绑定：同一受益神仙最多被一个助阵位绑定，重复选择会提示“该神仙已有助阵，请先解除原助阵绑定”。同一位重复选择原目标可成功。
- 首发／替补合计最多8名不同受益神仙，因此最多8组助阵同时产生收益；其余已开八卦位可保留助阵神仙和培养进度，解除原目标后再分配使用。
- 阵位洗炼固定消耗1015×10、20元宝；均匀随机选择不同来源／目标属性，将来源的5‰转到目标，来源不足时只转移现有值。四维比例总和不变，不产生负值。可重复洗炼覆盖旧预览，每次重新扣费。
- 法术洗炼相同消耗，随机增加1–5级，不超过500；未确认不生效，放弃不退款。有待处理预览时拒绝直接升级法术位，防止先升级后确认越界。
- 助阵属性以本轮计算的助阵神仙个人整数面板为输入，与客户端预览一致，不把上轮缓存战力再次加成。个人培养、飞升、转生、觉醒、自带被动及神仙自身显式来源保留；收藏、角色固定四维、称号、洞府生命及角色级显式来源只作用于上阵1～8位（含替补），不进入正逆助阵或背包神仙面板。被动法术仍以目标本轮基础属性 × 法术效果百分比 × 原表 `plus_rate` 计算，结果加到目标；没有独立助阵神仙时不产生增益。
- 目标按神仙 ID 固定绑定。神仙移到空位、与另一名神仙互换或在首发／替补位之间移动时，助阵四维及该助阵位的被动法术收益都跟随原受益神仙。下阵时保留绑定、暂停加成；重新上阵后恢复，原阵位的新神仙不会继承。删除受益神仙、主动清空目标或卸下助阵神仙会解除绑定；更换该位助阵神仙保留原目标。助阵法术跟随八卦位，助阵神仙自带法术跟随神仙。
- 结算进入统一永久属性与战力计算，旅途／仙盟等战斗沿用同一属性。正逆位均支持500级法术能力。

### 2026-11-13 一对一绑定与换位修复

旧实现仅保存 `cheer_<方向>_effect` 阵位号，导致换位／替换后收益对象变化，并允许多个正逆位集中加给一人。现在存档以 `cheer_targets` 保存“方向 → 受益神仙 ID”，`cheer_<方向>_effect` 仅作为原客户端兼容字段，按该神仙当前所在阵位实时生成。1032属性、重连登录及只读阵容查询继续使用原协议，客户端无需新增字段。

首次读取没有 `cheer_targets` 的旧存档时，将旧目标阵位解析为当时的神仙 ID；多个八卦位指向同一神仙，按正位1～8、逆位9～16顺序保留第一项，清空后续重复目标。助阵神仙、开位、等级、法术、洗炼及材料不删除、不重复收费；重复读取／保存不会重新按旧阵位绑定。旧目标位置无人时清空。历史最高战力保留，失去重复助阵的神仙当前战力会下降；可为清空的助阵位重新选择尚未绑定的上阵神仙。
