# 缘聚中秋与粽叶飘香：材料获取、合成奖励与概率分析（3.87）

> 2026-10-30更新：缘聚中秋与粽叶飘香均已按新参考图完成离线改造，常驻开放，分别独立随机掉料和开箱。月饼和粽子支持数量选择批量制作；通用材料2—4个等概率，四种专用材料各按0／1／2个的10%／70%／20%分布；两活动对应成品共用同一份奖励概率和数量，均接入旅途、天命胜利与蟠桃会。当前规则见[缘聚中秋说明](缘聚中秋离线活动实现说明.md)和[粽叶飘香说明](粽叶飘香离线活动实现说明.md)。第5节仅保留改造前的离线快照，原包考据不代表当前本地配置。

分析日期：2026-10-26。依据本仓库3.87原始客户端资源、随包配置、LuaJIT字节码及当前离线服实现。本文以原版机制为主，单独列出本地规则；未取得原服服务端奖池或原服抽取样本。

**可以确认材料来源线索、八种普通成品配方及开出的奖励类别；无法从现有原包还原具体奖品清单、数量分布和百分比。端午有随机制作出五星粽子的机制，中秋有全服累计制作后随机送礼的机制，两者不能与普通成品开箱混为一谈。**

证据标记：**【原表】**随包CSV；**【原文案】**客户端物品说明／活动提示；**【原客户端】**界面与消息处理；**【本地】**当前离线服规则，不代表官方；**【未知】**现有证据不足。

## 1. 两个活动的玩法对照

| 项目 | 缘聚中秋 | 粽叶飘香 |
|---|---|---|
| 通用材料 | 面粉1134 | 飘香粽叶1208 |
| 专用材料 | 紫薯、红豆、桂花、蛋莲馅料 | 碱水、红豆、咸肉、五仁糯米 |
| 单份配方 | 面粉15＋对应馅料15 | 飘香粽叶15＋对应糯米15 |
| 普通成品 | 四种月饼，各配方产出1个 | 四种粽子，各配方产出1个 |
| 成品开启类别 | 道具／装备／法术／元宝 | 道具／装备／法术／元宝 |
| 特殊机制 | 全服累计做月饼，嫦娥随机送礼 | 包任意粽子都有机会获得五星粽子1217 |
| 原版数值概率 | 未取得 | 未取得 |

制作成品、开启成品、特殊送礼是不同结算环节。配方中的“产出1个”不等于“开箱只给1件奖励”，也不等于证明所有服务端分支成功率100%。

### 3.3 五星粽子：制作时的特殊产出

【原文案】`rice1`：“包任意粽子都有可能获得神秘的五星粽子哦~”。五星粽子1217的物品来源写“活动期间合成”，开启说明为“使用后可开出神秘奖品”。

可以确认：四种普通粽子的制作均有机会触发五星粽子；它是独立物品，需要再开启获得奖励。这不是“打开普通粽子一定可能开出五星粽子”的证据，触发文案指向的是**包粽子环节**。

以下仍为【未知】：

- 四种配方的五星粽子产出概率是否相同，有无保底或次数修正。
- 五星粽子是额外附送，还是替换普通成品；现有文字和客户端结果列表不足以判定。
- 每次触发的数量，及五星粽子内部的具体奖品、品质和概率。

“五星粽子”这一名称不能证明里面必为五星装备／五星法术，也不能证明它固定开出圣母蟠桃。后者是当前本地配置。

## 4. 原版概率能确认到什么程度

| 随机环节 | 已知 | 缺失信息／结论 |
|---|---|---|
| 材料掉落 | 有活动渠道文案 | 无具体掉率，不能写成每战必掉 |
| 普通合成 | 配方明确指定目标，材料各15、目标1 | 没有四选一权重；不能给出随机25% |
| 普通成品开启 | 对应道具、装备、法术、元宝类别 | 无具体池、数量档位与权重，无法列官方百分比 |
| 五星粽子生成 | 包任意普通粽子均有机会 | 无触发率；不能猜成1%、5%或10% |
| 五星粽子开启 | 神秘奖品 | 内容与概率未知 |
| 中秋全服送礼 | 累计制作后随机送礼 | 门槛、抽样人群、中奖率与礼包内容未知 |

本次扫描361张提取CSV，检索19个材料／成品ID作为 `5|物品ID|…` 对象元组的引用，命中20个单元格，全部属于两张配方表。另检查 `product_desc` 中“月饼／粽子”的反向产出来源说明，没有找到可将具体奖励绑定到这些成品的记录。此范围内没有发现可直接使用的原版开箱奖池。

该检索不是对所有可能编码和服务端资源的穷尽证明。结果表示**当前保存证据不足**，不表示原服没有随机配置，也不表示未知奖励掉率为0。物品类别、排序值、配方中的15或1，都不能当成概率；其他系统的乾坤袋／装备合成奖池也不能移植为节日奖池。

若要计算原版概率，需要原服抽奖脚本／权重表，或按成品ID分别记录的大量开启样本。材料掉落、五星粽子制作触发、普通开箱、中秋额外送礼必须分别统计；“没开到”不等于概率为0。

## 5. 两项活动改造前的离线规则快照与原版差异

本节依据 [activity_seasonal.py](../network_redirect/activity_seasonal.py)、[activity_rules.json](../server_config/activity_rules.json)、[activity_party.py](../network_redirect/activity_party.py) 与 [journey.py](../network_redirect/journey.py)。下列均为**【本地】**，不能用来回答官方概率。

### 5.1 材料供给与制作

| 项目 | 当前本地行为 |
|---|---|
| 活动期 | rice／moon默认启用，时间窗为时间戳1至2147483647；不随现实端午／中秋日期自动开关 |
| 初次供给 | 每配置季首次查询活动状态，每种节日发通用材料60及四种专用材料各15；以活动开始时间标记该季，重复查询不重发 |
| 旅途 | 获胜结算按每个开放节日发通用材料1＋轮换专用材料1；成功扫荡沿用关卡结算，失败不发 |
| 蟠桃会 | 每次有效战斗结算按每个开放节日发通用材料1＋轮换专用材料1 |
| 天命之战 | 本次未发现该玩法接入上述节日材料发放函数，不能按原版文案认定本地已接入 |
| 制作 | 使用原包15＋15配方；每种节日每天最多100次，合法请求固定发对应普通成品1个 |
| 五星粽子 | 当前制作函数没有随机生成1217的分支，正常制作不会产出；已有1217仍可开启 |
| 中秋额外奖 | 角色个人累计每制作10个月饼发蟠桃1001×10；不是原版全服随机送礼 |

本地轮换覆盖四种专用材料，因此五仁糯米也能在本地旅途／蟠桃会取得；这是本地补全，与原文案标注的天命之战来源不同。轮换不是四种各25%的随机抽取。
