# 本地 TLS、SDK 登录与游戏业务接入

状态复核：2026-10-26。当前在 Android 6／ARM32 的3.87游戏内容上，使用本地账号登录、原版Lua界面及二进制协议，已接入战斗、旅途、阵容养成、装备、宠物、灵阵、仙盟和多项活动。本文保留早期登录／通信验证记录；它不是完整玩法清单。尚未接入和仅离线替代的部分见[游戏未接入服务器功能分析](游戏未接入服务器功能分析.md)。

## 启动和停止

双击项目根目录 **`启动游戏.command`** 或 **`启动本地离线游戏.command`**。两个入口共用 `start_game.py`：启动模拟器、停止已有重定向、启用离线服务并冷启动游戏；完成自检后，在游戏里点击“进入游戏”。当前通过本地注册／密码登录选择账号，每个账号独立保存角色、伙伴、背包及玩法进度；可按登录页选项一次性继承旧 `local-player` 的“本地行者”存档。数据保存在 `.runtime/offline/game.sqlite3`，重新启动不会清空。详见[本地账号登录](本地账号登录.md)。

2026-10-24 启动故障修复：后台服务此前会因一次 `adb shell ps -A` 查询超时而退出、卸载钩子，导致客户端提示“网络连接不通畅”。现在运行期间查询失败会保留监听器、连接和现有钩子，每两秒重试，并记录 `process_poll_retry`／`process_poll_recovered`；仍可正常停止服务。普通启动入口也会自动启动本地登录服务，避免只打开客户端。仅调试原渠道客户端可使用 `python3 start_game.py --client-only`。

修复验证：`tests.test_startup`、`tests.test_network_redirect`、`tests.test_offline_backend` 共 34 项通过，覆盖查询超时、设备暂时离线、恢复、停止及运行时限。实机通过默认 `start_game.py` 冷启动，DNS、IPv4／IPv6、Java 和 native HTTPS 自检成功；点击“进入游戏”后完成 3001／3002、1001／1002 登录并进入“本地行者”主界面。截图位于 `.runtime/startup-after.png`，会话日志位于 `.runtime/redirect/sessions/20261024T021039Z-2391e4cd/`。

```sh
.runtime/venv/bin/python redirect_game.py start --offline --probe
.runtime/venv/bin/python redirect_game.py status
.runtime/venv/bin/python redirect_game.py stop
```

如已有仅重定向模式运行，先 `stop` 再启动。双击 `停止本地重定向.command` 或 `停止游戏.command` 均会清理本工具创建的映射和钩子。退出离线模式后，重启游戏可销毁已有的 TLS context 和本地 SDK 内存状态。APK、Lua 文件及系统信任库不被改写。

## 三层实现

**TLS：** 同一回环端口 18770 识别 HTTP、TLS 与游戏 TCP。独立本地 CA 按请求 SNI 签发域名证书，私钥位于 `.runtime/offline/tls/`，目录 0700、私钥 0600；游戏进程中的 Java TrustManager 和 native OpenSSL／libcurl 加载此 CA。未采用“接受所有证书”的校验器，HTTPS 主机名校验仍开启。Java 实测协商 TLS 1.2；游戏自带旧 OpenSSL 只能协商 TLS 1.0，因此本地监听器兼容 TLS 1.0。该配置只用于 Mac 回环开发服务，不是公网部署配置。CA 不安装进系统；停止时恢复 Java 默认 socket factory，已有 context 随游戏进程结束释放。

**SDK：** 当前安装包的 `login/switchAccount` 入口已永久替换成本地登录窗口，停用360 SDK初始化、支付、论坛及相关组件；注册／密码或设备免登录凭据换取本地会话，再继续原Lua登录流程。Frida继续承担网络重定向、TLS兼容及玩法补丁。该流程不验证、复用或恢复真实360账号；对未匹配的旧统计／客服等HTTP路径返回501和JSON错误对象（ok=0）。具体安装包与账号机制见[本地账号登录](本地账号登录.md)。

**游戏业务：** 原客户端照常发送 LS 登录、BS 登录及查询。后端依据恢复的字段表编解码，再交给原消息分发和界面处理；没有直接调用 Lua 切换主场景。

| 请求／下发 | 当前行为 |
|---|---|
| 3001 → 3002 | 解析静态 Lua 登录数据，校验本地令牌，返回 60 秒内一次性票据与本地 BS 地址 |
| 1001 → 1002 | 校验账号、票据和 seed，建立本地会话 |
| 2998 / event 80 | 在角色进入消息前下发完整的最小初始化配置，以 `config_end=true` 完成客户端公共状态初始化 |
| 1017 | 下发 307 字段角色快照；阵容槽位数取客户端 `role_level_config.csv`，其余显式本地初值不代表官方服务器数值 |
| 1034 | 下发账号持久化的神仙列表；新角色初始伙伴为沙悟净，属性与战力走当前统一结算，数量多时分包 |
| 1035 | 下发账号存档中的 `attachments`，含自带法术及已有装备／道具；首包 `first_send=true`、后续追加 |
| 1033 → 1034、1035、2998 / event 1、1106 | 依次下发伙伴和物品列表、触发界面更新，并确认请求处理完成 |
| 1042 → 1034、1035、1046、1032、1047、2998 / event 23、1106 | 召唤校验、消耗、伙伴／魂魄／界魂入库及原界面结果；失败通过 event 55 提示 |
| 1094 → 1095 | 返回空好友／关注列表 |
| 1018 → 1020、1023 | 读取持久化旅途进度并返回对应地图／关卡，已有战斗、扫荡及领奖结算，见[旅途说明](旅途模块规则与调试.md) |
| 1016 → 2996、配置、1017、1034、1035 | 当前服务生命周期内，凭 random_key 重连并恢复角色、伙伴和包裹快照 |
| 1105 | 按客户端最后收到的服务端序号重传缓存响应；无遗漏时下发 1106 结束等待 |
| 2999 → 2999 | 心跳、服务器时间和会话 key |
| 其他已实现业务请求 | 分发给角色、养成、活动、仙盟、福利等模块；完整范围见各专项文档 |
| 无业务路由的请求 | 记录 `game_unimplemented`；有有效请求序号时返回事件55说明及1106完成通知 |

最小公共配置补齐客户端初始化所需的各配置节，并显式关闭尚不可用的功能，避免阵容依赖的公共状态未初始化。旧存档缺少 `cortege_count` 时按角色等级从 CSV 补齐，缺少 `attachments` 时补为空列表；保留已有角色、伙伴和物品数据。

## 协议与兼容修正

- 包头为小端 `uint16 type + uint32 total_size + uint32 connection_id`，共 10 字节；限制单包 32768 字节。
- `d` 为 IEEE double，`s` 为 NUL 结尾字符串，`S[n]` 为固定长度字符串。结构数组使用前一个单字节字段（`B` 或 `b`）作为数量，不额外写长度；当前支持已验证的末尾结构数组及标量记录。依据：[protocol_tables.json](../analysis/evidence/protocol_tables.json)、[native_protocol.asm](../analysis/evidence/native_protocol.asm)。
- 带请求序号的业务响应使用独立、连续递增的服务端序号，以 `1106.req_serial_num` 关联原请求，避免多条响应被客户端当作重复包丢弃。当前缓存最近 256 条响应供 `1105` 重传，缓存和序号跨 TCP 重连保留；超出缓存范围会记录 `game_replay_unavailable`。
- `AI_NUMERICHOST` 的试探解析不重写，避免 Android 把普通域名误判成非法数字地址；正常域名查询和 TCP connect 仍转到本地。
- 修正旧 `CurlSocket::getSocketFd` 把异步连接暂未取得 socket 误判为失败的问题。补丁仅在进程内生效，校验 ARM32 与已验证函数偏移；不适用于任意其他版本 native 库。

覆盖范围仍限于已附加的游戏进程及 TCP API；它不是全设备网络隔离。SDK 子进程的附加存在短暂窗口。完整覆盖边界见 [本地重定向说明](本地重定向.md)。
