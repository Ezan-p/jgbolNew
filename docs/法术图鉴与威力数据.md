### 1.1 关键字段

| 字段 | 含义 |
|---|---|
| `intensity` | **法术基础强度**（1 级值） |
| `upgrade_plus` | **每升 1 级增加的强度** |
| `begin_level` / `top_level` | 起始等级／最高等级；可获取法术均为 1→10 级 |
| `use_probability` | 每回合尝试触发时的概率（%）；单体 15，群体 10 |
| `use_mode` | 1＝主动，2＝被动 |
| `effect_target` | 1＝单体，2＝群体 |
| `effect_field` | 1 攻击、2 防御、3 法力、4 法术强度、5 生命 |
| `quality` | 品质 1–5；主动单体多为 2–5，群体为 3–5 |

### 1.2 强度公式

```text
第 N 级强度 = intensity + upgrade_plus × (N − 1)
```

按原表 `top_level=10` 计算，主动法术的 10 级强度即本文「Lv10 强度」列。该线性关系与客户端技能记录的 `base_intensity`／`effect_plus` 字段一致；服务端具体取整和增益顺序属于【B】。

### 1.3 本地战斗结算口径【B】

本地战斗现使用 [V1.1候选重建规则](战斗伤害重建V1.1.md)：普攻 `max(0.05A,A-D)`；法术 `S=0.25A+3M`，再按强度倍率、配置目标数、防御与法抗结算。强度与触发率分开使用；此规则仍属【B】，不是已证实的原服公式。

## 附录 B：复核方式

所有数值均可在以下 UTF-8 副本中逐值核对：

```text
analysis/configs/skill_name.csv
analysis/configs/skill_base.csv
analysis/configs/rulai_skill_base.csv
analysis/configs/awaken_skill_conf.csv
analysis/configs/awaken_skill_rate.csv
analysis/configs/skill_advaced_conf.csv
analysis/configs/ext_skill.csv
```

Lv10 强度的复核公式：

```python
lv10 = float(intensity) + float(upgrade_plus) * (top_level - 1)
```

例如 203 番天印：`160 + 30 × 9 = 430`；202 袖里乾坤：`155 + 29 × 9 = 416`。
