# 游戏玩法等级开放说明

核对版本：原版客户端 **3.87**；更新日期：2026-10-28。

本次从原包枚举核对全部 **42个活动ID**，扫描147个含等级引用的Lua模块，校验14份含开放条件的CSV与原包逐单元格一致，并将已实现玩法缺失的入口／操作等级校验补到离线服务端。太虚幻境恢复为**外层入口与商店12级、历劫50级**，仙盟元宝捐献执行**36级或VIP1**。

**可恢复的原版固定条件已接入；不能把全部原服开放规则宣称为100%复原。** 原包不含正式服下发的全部等级参数与运营日历；另外，淘金、邀友、科举等14个活动尚无完整离线业务。本次不将“有入口／有等级表”冒充这些玩法已经实现。

## 一、证据与阅读方式

- **A：原包明确**。可由原版Lua分支、CSV或协议字段直接证明，离线按原条件执行。
- **B：服务器参数／既有离线补值**。原版读取服务器字段，但原服实际数值没有保存在包内；列出当前离线值，不将其标成原版常量。
- **未设固定等级**：只表示原版活动公共入口函数返回0，不能推导“原服1级就可参与全部操作”。活动期、VIP、前置任务、物品、对象等级等仍可能限制参与。
