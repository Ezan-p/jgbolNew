# 灵宠仙地宠物商店商品池与上架概率

更新日期：2026-11-09（第二次调整）。适用范围：当前工作区服务端源码与配置；已有APK需包含对应更新才适用。

商店现在固定6个位置：下品镇魂符、中品镇魂符、驯养丹占前3格，后3格每天从其余6种商品中加权抽取3种，不重复。新增驯养宝箱×1、每日限购1份；驯养丹×5的每日限购从10份改为3份。本文替代上一版“8种商品分别独立判定上架”的方案。

商品组成、固定位置、随机位置数量及材料限购按需求实现；抽取权重、驯养宝箱价格和解锁门槛为本次离线设计值，不代表原服概率。“每次抽取”沿用每日刷新周期，重复打开商店不重抽。

镇魂符每份数量、价格、解锁门槛和额度公式沿用原有规则：

```text
L = 3 + floor(累计声望 / 100)
剩余次数 = max(0, 当日限购份数 - 当日该道具已购买份数)
```

例如累计声望1000时，每种已上架镇魂符各有13份额度；驯养丹为3份，三种升星材料各5份，驯养宝箱为1份。累计声望增长只增加镇魂符额度。

驯养丹每天买满3份到账15颗，花费60声望。妖王丹、仙气灵、神元精在各自上架日买满5份，分别花费200、300、500声望。驯养宝箱上架时只能买1个，花费60声望；购买获得宝箱，需另行打开，不会直接兑换为驯养丹。未解锁的商品仍可占据货架，但购买按钮受累计声望门槛限制。

## 2. 随机池权重与实际概率

先放入3种固定商品，然后在以下6种商品中按剩余权重抽取3轮；每轮抽中后移出候选池。同一商品每天只占一格。

| 随机商品 | 初始权重 | 第1轮抽中概率 | 3轮内至少抽中一次（每日上架概率） |
|---|---:|---:|---:|
| 上品镇魂符 | 25 | 25% | 68.5353% |
| 神品镇魂符 | 10 | 10% | 35.1133% |
| 妖王丹 | 25 | 25% | 68.5353% |
| 仙气灵 | 20 | 20% | 60.1313% |
| 神元精 | 5 | 5% | 18.6712% |
| 驯养宝箱 | 15 | 15% | 49.0137% |
| 合计 | 100 | 100% | 300%（每天恰好3种） |

设计上让常用上品符、妖王丹较容易出现，仙气灵次之，宝箱约每两天出现一次，神品符与神元精更稀有。这里的间隔是长期平均，不保证隔固定天数出现，也没有额外保底。

权重不是最终上架百分比，也不能简单将第一轮概率乘3。第2、3轮只在未抽中的商品中重新归一化。例如第一轮抽中上品符后，剩余总权重为75，神品符下一轮概率变为10/75。

实际概率通过穷举 `6×5×4=120` 条有序抽取路径精确计算，再四舍五入到4位小数。若前三次抽取的不同商品为a、b、c，则：

```text
P(a,b,c) = w[a]/100 × w[b]/(100-w[a]) × w[c]/(100-w[a]-w[b])
P(商品i上架) = 所有包含i的有序抽取路径概率之和
```

选中后按商品池顺序展示后3格，即上品符、神品符、妖王丹、仙气灵、神元精、驯养宝箱的相对顺序；展示排序不影响抽取概率。

## 3. 刷新与供应量

- 每个角色以北京时间00:00为每日边界，新一天首次查询生成并保存3种随机商品。固定商品始终为前3格，总计始终6格。
- 退出重进、重复查询、服务端重启不重抽、不恢复已用额度。没有付费刷新。
- 抽取不受解锁门槛、余额或是否已买满影响。购买完的商品保留在货架，剩余次数为0，不用别的商品补位。
- 上架概率与捕捉成功率不同：四种镇魂符捕捉成功率仍为35%／60%／85%／100%。

下面假设全部解锁、声望充足、每天买满所需材料，仅为供应期望，不是每天保底或养成完成时间预测。

| 商品 | 上架当天最多获得 | 日均数量期望 | 30天数量期望 |
|---|---:|---:|---:|
| 驯养丹 | 15颗 | 15颗 | 450颗 |
| 妖王丹 | 5颗 | 约3.4268颗 | 约102.8029颗 |

宝箱沿用[pet_rules.json](../server_config/pet_rules.json)中的开启奖池：10颗驯养丹权重30、15颗权重50、20颗权重20，分别对应30%、50%、20%，每箱期望14.5颗。本次不修改宝箱内容。假设商店宝箱全部买入并打开，可额外提供约 `0.4901365×14.5=7.1070` 颗驯养丹／日；连同固定驯养丹共约22.1070颗／日、663.2094颗／30日。宠物任务等其他来源的宝箱不计入此数。

## 4. 配置与旧档兼容

配置位于[guild_rules.json](../server_config/guild_rules.json)。商品数组保持原有ID顺序，并在末尾追加宝箱：`1338、1339、1340、1341、1345、1347、1348、1349、1346`。这与前端“固定3格＋随机3格”的展示顺序不同。

| 配置字段 | 当前含义 |
|---|---|
| `pet_shop_items` | 奖励类型、道具ID、每份数量、等级 |
| `pet_shop_reputation` | 每份声望价格：20、40、60、100、20、40、60、100、60 |
| `hunt_shop_unlock` | 累计声望门槛：30、50、100、200、0、50、100、200、50 |
| `pet_shop_fixed_items` | 固定商品ID：1338、1339、1345 |
| `pet_shop_random_slots` | 随机位置数：3 |
| `pet_shop_weights` | 抽取权重：0、0、25、10、0、25、20、5、15；固定商品不进入抽取池 |
| `pet_shop_daily_limits` | 0、0、0、0、3、5、5、5、1；0仅用于镇魂符，表示采用累计声望公式 |

上一版 `pet_shop_listing_percent` 已移除，不再使用独立百分比判定。规则校验要求固定3种商品、随机3格，随机候选权重为正，宝箱／驯养丹／升星材料分别限购1／3／5份。

[guild_hunt.py](../network_redirect/guild_hunt.py)保存当天6格商品、刷新日期、版本和按道具ID记录的购买次数。此次版本升为3，旧版当日列表首次访问时重新生成一次，保留已购记录、货币和背包。驯养丹当天已买2份时剩1份，已买3～10份时剩0份，不追回已发道具，次日恢复3份。新增宝箱当天额度为1。

更早的固定6格存档仍先将第3～6格镇魂符购买记录迁移到道具ID，旧蟠桃／银两记录不占新商品额度。升级或跨日后需重新查询商店才能购买，避免旧行号误用到新列表；显式携带过期 `shop_day` 的请求也会拒绝。旧客户端使用最近一次查询日期兼容校验。服务端始终把可见行号映射到实际商品，扣费、发奖、库存保持一致。
