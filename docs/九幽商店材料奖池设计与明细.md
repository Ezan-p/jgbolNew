# 九幽商店材料奖池设计与明细

更新：2026-10-31；当前版本：`2026-10-31-reborn-equip-v7`。按最新要求移除v5中的14种普通精魄和19种高级精魄，炼药材料仍不入池。材料身份及用途来自原版消耗表【A】，价格、数量、限购及上架方案属于本地设计【B】。

## 当前范围与刷新规则

候选池共11种：神仙转生5种（轮回舍利、三种转生石、精魄石），装备封神／铸造6种（补天石、神装灵器、神源水晶、三种精华）。精魄石10000是仙脉消耗材料，仍保留；普通和高级精魄全部移除，本商店不再覆盖仙脉所需的完整精魄种类。

每天北京时间00:00刷新6件，神仙转生组5选3、装备封神组6选3。将精魄石并入转生组，取消原仙脉独立分组。每组按权重连续抽3次，抽中后移出候选池，因此每日无重复；精魄石也按权重参与抽取，并非每日固定上架。

本轮将白虎精华、玄武精华、青龙精华的每份价格从300提高至500魂晶；每份仍为250个、每日限兑4份，权重及上架概率不变。上架免费，无付费刷新；购买按份扣魂晶，成功兑换确定获得列明数量。当天重复查询、重登、重启沿用已保存货架，跨日重置限购，不累计错过天数。

配置升级v7后首次访问自动刷新旧货架并清空旧限购。此前已获得的精魄、炼药材料、魂晶及养成进度保留，不回收库存。今后变更池子仍须更新版本号。

## 概率口径与明细

“每日上架概率”指该材料出现在当天6件商品中的概率。对同组所有包含目标材料的有序三元组求和：

`Pᵢ = Σ(i∈{a,b,c}) [wₐ/W × wᵦ/(W−wₐ) × w𝒸/(W−wₐ−wᵦ)]`

其中a、b、c互不相同，W为该组总权重。每组上架概率合计300%，两组合计600%，对应6件商品；购买已上架商品获得材料的概率为100%。表内概率保留两位小数。

## 数量、价格与消费容量

一转需要伏心转生石20＋轮回舍利10，上架日分别最多购买20、20。无上转生石最多购买4/日，九转需要40，单靠商店至少需10个该材料上架日。精魄石每份300、每日最多1500，用于各仙脉节点300—1600的原有消耗；已移除的精魄需通过其他现有渠道获得，原仙脉配方不变。

装备封神单件需要补天石20，单次上架最多买6，至少4个上架日；铸造二级需要神装灵器5＋神源水晶5＋对应精华2500，各至少3个上架日。这是从零仅靠本店购买的下限，不是连续自然日保证。

普通全天挂机达到所在狱战力上限时约864—3168魂晶，双倍1728—6336。商品每份240—1000魂晶；每日6件全买满的理论支出为8,760—11,400魂晶，按上架概率加权平均约9,888.38魂晶，供玩家按当前养成需求取舍，不要求每天买满。
