# 九幽商店材料奖池设计与明细

更新：2026-11-10；当前版本：`2026-11-10-reborn-equip-v11`。本轮调整三种精华的每份数量、价格与限兑份数，商品整体仍为800—2,000魂晶；继续保留11种材料，普通／高级精魄和炼药材料仍不入池。材料身份及用途来自原版消耗表【A】，价格、数量、限购及上架方案属于本地设计【B】。

## 当前范围与刷新规则

候选池共11种：神仙转生5种（轮回舍利、三种转生石、精魄石），装备封神／铸造6种（补天石、神装灵器、神源水晶、三种精华）。精魄石10000是仙脉消耗材料，仍保留；普通和高级精魄全部移除，本商店不再覆盖仙脉所需的完整精魄种类。

每天北京时间00:00刷新6件，神仙转生组5选3、装备封神组6选3。将精魄石并入转生组，取消原仙脉独立分组。每组按权重连续抽3次，抽中后移出候选池，因此每日无重复；精魄石也按权重参与抽取，并非每日固定上架。

本轮将白虎、玄武、青龙精华各调整为每份100个、1,000魂晶、每日限兑5份，每种上架日最多获得500个。其余8种商品沿用原配置，全部商品权重及上架概率不变。上架免费，无付费刷新；购买按份扣魂晶，成功兑换确定获得列明数量。当天重复查询、重登、重启沿用已保存货架，跨日重置限购，不累计错过天数。

配置升级v11后首次访问自动刷新旧货架并清空旧限购。此前已获得的精魄、炼药材料、魂晶及养成进度保留，不回收库存。今后变更池子仍须更新版本号。

## 概率口径与明细

“每日上架概率”指该材料出现在当天6件商品中的概率。对同组所有包含目标材料的有序三元组求和：

`Pᵢ = Σ(i∈{a,b,c}) [wₐ/W × wᵦ/(W−wₐ) × w𝒸/(W−wₐ−wᵦ)]`

其中a、b、c互不相同，W为该组总权重。每组上架概率合计300%，两组合计600%，对应6件商品；购买已上架商品获得材料的概率为100%。表内概率保留两位小数。

## 数量、价格与消费容量

一转需要伏心转生石20＋轮回舍利10，上架日分别最多购买20、20。无上转生石最多购买4/日，九转需要40，单靠商店至少需10个该材料上架日。精魄石每份300、每日最多1500，用于各仙脉节点300—1600的原有消耗；已移除的精魄需通过其他现有渠道获得，原仙脉配方不变。

装备封神单件需要补天石20，单次上架最多买6，至少4个上架日；铸造二级需要神装灵器5＋神源水晶5＋对应精华2500：神装灵器、神源水晶各至少3个上架日；对应精华每个上架日最多500个，至少5个上架日。这是从零仅靠本店购买的下限，不是连续自然日保证。

收益参照为第九狱达到战力收益上限、普通挂机24小时：`86400 ÷ 300 × 11 = 3,168`魂晶。本轮价格下，从零余额起，任一上架商品均可购买1份；按所选价格组合最多购买3份，例如购买3份精华需3,000魂晶、获得对应精华300个。最便宜4份需3,200，超过普通全天收益。因此此前“普通一天最多买一份”的价格约束不再适用，不新增每日只能购买一种的硬限制。

较低狱层达到各自战力上限时，普通全天收益为864—2,880魂晶，按实际收益与上架商品选择；第一狱864魂晶可买1份已上架的800档商品，较高档需积攒。第九狱全天双倍收益6,336魂晶，按最低价计算最多7份，实际还受当天货架与每种商品限购影响。历史余额、首胜及其他奖励可支持额外购买，原有每种商品每日限兑2—5份继续生效。

每日6件全买满的理论支出调整为22,600—27,800魂晶，按上架概率加权平均约25,457.16魂晶；上述养成所需上架日下限均以余额充足为前提。

## 实现与验证

[配置](../server_config/activity_rules.json)：`abyss_shop`、`abyss_shop_category_slots`、`abyss_shop_revision`。[加载校验](../network_redirect/activity.py)依据九转与装备封神／铸造消耗表构建白名单，仙脉部分只保留10000精魄石；拒绝普通／高级精魄、炼药材料、缺失／重复材料、非法权重及非3＋3名额。

[商店实现](../network_redirect/activity_abyss.py)继续使用1329请求、173回包及原6格界面。携带旧`shop_day`／`shop_revision`的购买会被拒绝；未携带这两个字段的旧客户端沿用原兼容逻辑。

[专项测试](../tests/test_abyss_shop.py)覆盖11种材料逐项购买、扣费、数量、限购、重放、原子失败、旧精魄货架迁移及库存保留、跨日、重启；对12000个角色检查每日3＋3名额、无重复、全池可达，并将实测上架率与有序三元组解析概率比较。测试使用临时存档。

v6验证：商店、九幽活动与九狱数值共27项测试通过；11行明细与配置逐项核对。v7调价验证：确认仅三种精华价格变为500魂晶，数量、限购、权重未变；逐项兑换扣费／限购／重放及版本迁移两项回归通过，消费容量按新价格重算。

v8调价验证：上述27项回归全部通过；临时存档另行验证第九狱24小时普通收益3,168、双倍6,336，11种商品分别购买1份后普通日收益余额归零，再买同种或另一种均失败且不扣资源；v7旧价格货架迁移为每份3,168，保留魂晶与库存，拒绝携带旧版本的购买请求。

v9调价验证：上述27项回归全部通过；确认只调整11种商品价格与货架版本，价格范围2,500—4,000。逐项验证3,168魂晶预算下低档买1份后无法再买、高档余额不足时原子拒绝；穷举转生组全部上架组合，均至少包含一种当日普通满收益可购商品。v8货架自动迁移为梯度价格，保留库存与魂晶，并拒绝旧版本购买请求。

v10调价验证：上述27项回归全部通过；确认仅修改商品价格与货架版本，11行文档价格与配置一致，范围800—2,000。临时存档验证v9货架迁移后保留魂晶与库存、拒绝旧版本购买请求；3,168魂晶购买3份低价商品后，第四份因余额不足被原子拒绝。

v11精华调整验证：上述27项回归全部通过；11种商品的文档数量、价格、限兑、当日最多数量及权重与配置逐项一致。临时存档验证三种精华分别兑换5份扣5,000魂晶并获得500个，余额仍够时第6份也被限购拒绝；v10旧货架迁移保留魂晶与库存，并拒绝旧版本购买请求。
