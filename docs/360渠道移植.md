## 构建内容

| 部分 | 来源及处理 |
|---|---|
| 游戏资源、Lua、索引 | 原始 3.87 的 `assets/release_`，逐文件比对一致 |
| native 引擎与语音库 | 原始 3.87 的 `lib`，逐文件比对一致 |
| Cocos2dx Java 层 | 3.87，与新引擎匹配 |
| Android 渠道集成 | 3.79 的 SDK、资源、Manifest 配置、主 Activity 和 ThirdPartyAPI |
| 语音模型 | 3.87 的 `assets/model` |
| 渠道号与协议 | `107 / p360_na`；使用 3.87 已有的 `access_token` 登录分支 |
| 应用包名 | `com.sygame.jingubang.p360`，沿用 360 配置 |
| 主 Activity 类名 | `com.sygame.jingubang.uc.xiyoujilua`，匹配 3.87 原生库的 JNI 导出 |
| APK 版本 | `versionName=3.87`、`versionCode=87` |

主 Activity 及其内部类从旧命名空间迁到 JNI 需要的类名；SDK 应用包名和资源 ID 保留旧值。主 Activity 中全部 native 声明均已核对新库导出。没有替换 3.87 的业务脚本，也没有仅通过改渠道号来模拟 SDK 接入。

该构建复用旧版 Android 渠道集成，因此支付、切换账号等 SDK 功能也随该集成来自 3.79；这些功能未验证。本次不是完整的所有渠道功能兼容性认证。

## 构建与恢复

```sh
# 按当前默认配置重建
python3 build_apk.py
# 无论当前配置是什么，单独构建 360 移植包
python3 build_channel360.py
# 重新安装当前包，保留该包应用数据
python3 android_emulator/run.py --config game.json install
```

构建依赖项目已有 JDK 17、Android build-tools 35.0.0，以及 `.runtime/tools/apktool.jar`（Apktool 2.12.1）。工具下载自项目官方发布地址：`https://github.com/iBotPeaches/Apktool/releases/download/v2.12.1/apktool_2.12.1.jar`，本次文件 SHA-256 为 `66cf4524a4a45a7f56567d08b2c9b6ec237bcdd78cee69fd4a59c8a0243aeafa`。

修改 APK 后无法沿用发行方签名。本地测试密钥保存在 `.runtime/channel360/local-test.p12`；它仅用于本地移植测试，不代表发行方身份。保留该密钥可继续覆盖安装本次构建。新签名是否被远端 SDK 接受尚未验证。

两个原始目录 `jgbol3.79/`、`jgbol3.87/` 以及原始 UC APK 均保留。UC 包和移植包独立安装，没有删除或迁移 UC 应用数据。

仅启动原始 UC 版：

```sh
python3 android_emulator/run.py --config game.uc.json launch
```

恢复默认为 UC 版：

```sh
cp game.uc.json game.json
python3 android_emulator/run.py --config game.json restart-web
python3 start_game.py
```
