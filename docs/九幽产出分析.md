## 一 统计口径

| 项目 | 本文口径 |
|---|---|
| 参与条件 | 主角70级开放九幽，挂机层已解锁 |
| 一天 | 在同一层连续挂机24小时，288个完整300秒结算周期 |
| 普通／双倍 | 普通每周期1次掉落；双倍每周期独立抽取2次，并使魂晶×2 |
| 魂晶上限 | 战力达到该狱收益门槛；低战力按公式下降 |
| 概率道具 | 均为长期数量期望，保留两位小数，单日实际是整数且会波动，无每日保底 |
| 离线上限 | 单次补算最近48小时，最多576个完整周期；超过部分不计挂机收益 |
| 存储条件 | 临时背包有空间接收新种类，并及时领取；同类型、同等级自动堆叠 |
| 净收益 | 挂机表为产出总额；未扣事件偷窃、商店消费、祈福或其他养成消耗 |

一天只挂机部分时间时，按实际完整周期数除以288缩放。一天换层时，按各层实际结算周期分别相加；不能把九狱每日数相加作为一个角色的日产出。切换挂机层前会先结算原层；击败冥仙后也需自行选择已解锁的挂机层，不会自动将挂机层切到最新进度。

双倍10元宝／小时，连续24小时成本240元宝；只有完整300秒周期都处于双倍窗口内才翻倍。魂晶的6倍调整不使物品掉落也变成6倍，物品仍按上述1次／2次抽取。

## 五 击败冥仙获得多少魂晶与材料

### 1. 首胜规则

每层魂晶按`2 × max(1, 原表魂晶数量 // 100)`计算，先向下取整，再乘2；不是直接发原表数万魂晶。每次胜利推进一层，每层只可领一次，通关81层后不能重复刷最终层。

每天最多5场有效冥仙战斗，失败／平局也扣次数，但无胜利奖励。因此没有固定的“每日冥仙魂晶”：当天获得多少，等于当天实际首次击败各层奖励之和；全通关后此项为0。下表每狱9层的合计至少跨两个挑战日，不能当作每日固定收入。

## 八 随机事件、榜奖与一次性补给

### 1. 随机事件

每小时生成1个事件，5类等概率，队列最多5个，队满期间不积压。及时处理、队列不满时，连续24小时可产生24个新事件；仅离线24小时后统一回来，队列最多保留5个，不会积累24个。跨日携带的旧队列另算，因此24不是“每日可处理事件数”的硬上限。

| 事件 | 获得奖励的条件 | 产出或消耗 |
|---|---|---|
| 猜数字 | 4次机会内猜中 | 从公共奖励池等概率选1项 |
| 祈福 | 支付选定消耗 | 同上；消耗普通蟠桃1颗、仙丹1023×1或银币10,000之一 |
| 遇魂仙 | 累计伤害击杀 | 同上；前3次免费，此后优先扣仙丹1023×1，否则每次20元宝 |
| 妙手空空 | 查看即结算 | 失去0—100魂晶，受当前余额限制；不发正奖励 |
| 火眼金睛 | 选中正确神仙 | 从公共奖励池等概率选1项 |

公共奖励池为普通蟠桃1001×10、仙丹1023×1、伏心转生石1330×5，三项各1/3，**只发其中一项，不是同时发三项**。若每天成功结算有奖励事件S个，对应毛产出期望分别为`10S/3、S/3、5S/3`；再扣祈福与额外魂仙挑战的实际消耗。S取决于在线处理频率、成功率、阵容和选择，不能给所有玩家统一固定日产量。

余额始终≥100时，每次妙手空空平均损失50魂晶。若24个新事件均被及时处理，妙手空空个数期望为4.8，魂晶损失期望约240／天；余额不足、处理不足或存在旧队列时需重新计算。该损失不影响挂机产出表的毛收入，但影响最终可兑换余额。
